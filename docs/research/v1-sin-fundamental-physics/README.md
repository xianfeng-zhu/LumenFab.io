## 五份研究笔记

| # | 特性 | 文件 | 一句话结论 |
|---|------|------|-----------|
| 1 | 折射率 ~2.00 | [sin-refractive-index-physics.md](sin-refractive-index-physics.md) | 根源是 Si-N 键的离子性导致平均能隙 ~22.6 eV（Si ~11.4 eV），能隙平方反比压下 n |
| 2 | 透明窗口 0.25–8.3 μm | [sin-transparency-window-physics.md](sin-transparency-window-physics.md) | UV 截止由 5eV 带隙决定，IR 截止由 Si-N 声子 ~900 cm⁻¹ 倍频决定（比 Si-O ~1100 cm⁻¹ 更深） |
| 3 | 低热光系数 dn/dT | [sin-thermo-optic-physics.md](sin-thermo-optic-physics.md) | 宽带隙削弱 Kramers-Kronig 耦合 + 低 n 通过 f(n) 压缩 dn/dT = 两项叠加 ~7× 差异 |
| 4 | 超低传输损耗 | [sin-rayleigh-scattering-physics.md](sin-rayleigh-scattering-physics.md) | Payne-Lacey: α ∝ (n₁²−n₂²)² → SiN 介电反差 ~1/27 × 侧壁场强 ~1/3-5 → 乘积 ~100-200× |
| 5 | 非晶结构 | [sin-amorphous-structure-physics.md](sin-amorphous-structure-physics.md) | 连续无规网络 → 无晶界散射 + 光学各向同性 + 缺陷可退火 — 全非晶波导体系最"干净" |

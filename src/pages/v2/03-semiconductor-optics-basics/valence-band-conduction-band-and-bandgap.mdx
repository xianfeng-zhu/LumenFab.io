## One-Sentence Answer

价带和导带是半导体里电子可处在的两组能量状态；带隙是价带顶和导带底之间的能量差，它决定材料是否容易导电、吸光和发光。

## Why This Exists

后面讲 InP、GaAs、Si、DFB、EML、PD 和调制器时，很多判断都要回到同一个问题：电子能不能从一个能量状态跳到另一个状态，以及这次跃迁更容易把能量给光子还是给晶格振动。

## 能带的起源：从原子轨道到晶体

孤立原子中，电子只能占据特定的分立能级（轨道）。当大量原子排列成晶体、原子间距缩短到原子半径量级时，相邻原子的电子轨道开始重叠。泡利不相容原理要求没有两个电子可以处于完全相同的量子态，因此原本每个原子都一样的能级被迫**分裂**成一组彼此略有差异的能级。原子数量级（~10²²/cm³）的能级密集排列，形成了连续的能量区间——这就是**能带**。

能带之间的空隙称为带隙——在这些能量区域内，没有允许的电子状态存在。

### 导带底（CBM）和价带顶（VBM）

能带不是平线，而是随电子动量和晶格结构变化的弯曲函数（详见 E(k) 图）。两个最关键的位置：

- **价带顶（VBM / Valence Band Maximum）**：价带中能量的最高点。常温下，价带几乎所有状态被电子填满，VBM 是电子"离导带最近"的起跳位置。
- **导带底（CBM / Conduction Band Minimum）**：导带中能量的最低点。电子被注入导带后，通过发射声子逐级跌落，最终"休息"在这里。

**带隙 E_g 严格定义为 CBM 和 VBM 之间的能量差**：E_g = E_CBM − E_VBM。几乎所有半导体光学性质都由这两个特定点的位置决定。

## 带隙如何决定吸收、透明与双光子吸收

### 单光子：门槛逻辑

一个光子能否被材料吸收，取决于它的能量是否足够把电子从价带踢到导带：

```
hν < E_g → 光子能量不够 → 电子跳不上去 → 材料透明
hν ≥ E_g → 光子能量够 → 电子可以跃迁 → 吸收发生
```

一旦被吸收，光子消失，电子跳到导带中。如果光子能量恰好等于 E_g，电子落在 CBM；如果 hν > E_g，电子落在导带中较高的位置，多余的能量通过发射声子（晶格振动）耗散为热，电子最终回到 CBM。能量转化路径：

```
光子能量 hν ──→ E_g：用来建立电子-空穴对（"存在的门票"）
            └→ hν − E_g：通过发射声子变成热量
```

### 双光子吸收（TPA）：两个光子凑齐了一张票

两个光子几乎同时到达，总能量加起来跨越带隙：

```
2hν ≥ E_g → TPA 可以发生
2hν < E_g → TPA 被抑制
```

在 1550 nm 通信波段（单光子约 0.8 eV）：

| 材料 | E_g | 2 × 0.8 eV | TPA？ | 原因 |
|------|-----|-----------|-------|------|
| Si | 1.12 eV | 1.6 eV | **是** | 1.6 > 1.12，两个光子够 |
| InP | 1.34 eV | 1.6 eV | 是 | 1.6 > 1.34 |
| GaAs | 1.42 eV | 1.6 eV | 是 | 1.6 > 1.42 |
| Si₃N₄ | **5 eV** | 1.6 eV | **否** | 1.6 &lt;&lt; 5，两个也不够 |

SiN 的 5 eV 带隙在通信波段面前是座"高山"——单个光子爬不过去（0.8 < 5），两个光子也爬不过去（1.6 < 5）。这就是 SiN 在通信波段无 TPA、可承载高功率的物理根源。

### 电子伏特（eV）

讨论带隙时用的单位是电子伏特（eV）：1 eV = 一个电子在 1 伏特电势差下加速所获得的动能，约 1.6 × 10⁻¹⁹ J。用 eV 是因为单个原子/电子/光子的能量交换正好落在这个数量级，用焦耳反而累赘。

光子能量与波长的换算：E(eV) = 1240 / λ(nm)。1550 nm 光子 ≈ 0.8 eV，可见光 ≈ 1.8–3.1 eV。

## Physical Principle

总结以上：孤立原子的电子能级是离散的。很多原子排成晶体后，原子轨道重叠，能级分裂展宽成能带。

- **Valence band**：较低能量的允许带，常温下几乎所有状态被电子填满。VBM 是价带的最高点。
- **Conduction band**：较高能量的允许带，CBM 是导带的最低点。电子进入导带后可以自由移动、参与导电。
- **Bandgap**：CBM 和 VBM 之间电子不能稳定停留的能量区间。它决定材料是否容易导电、吸光和发光。

## Engineering Implementation

在光器件里，带隙不只是教科书概念。它决定：

- 激光器或 LED 可能发出什么波长的光。
- 光探测器能吸收什么能量范围的光子。
- 材料在目标波长下是透明、吸收还是提供增益。
- 异质结构中载流子和光场能否被有效约束。

## Key Metrics

- `Eg`：bandgap energy。
- 对应波长：粗略用 `E = hc/lambda` 连接光子能量和波长。
- 吸收边：材料开始强吸收的光子能量附近。
- 温度系数：温度变化会改变 bandgap 和器件工作点。

## Common Misconceptions

- 价带和导带不是芯片里的两层材料。
- 带隙不是一个可以用显微镜看到的几何空洞。
- 带隙越大不等于材料越好，只是对应的光子能量和器件用途不同。

## Short Version

半导体不是简单地"导电"或"不导电"。它的核心是电子能量状态可以被材料、掺杂、偏压和光子调控。价带、导带和带隙是理解光源、探测器、调制器和材料平台的入口。

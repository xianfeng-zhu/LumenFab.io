## One-Sentence Answer

半导体激光器的光不是随便在芯片里乱跑；垂直异质结构和横向脊形或掩埋结构把光学模式限制在有源区附近，让增益和模式重叠。

## Why This Exists

很多 DFB 激光器图只画光栅和有源区，容易让人误以为输出方向只靠“端面镜”或“光栅”。实际器件需要三维约束：纵向、垂直和横向。

## Physical Principle

垂直方向通常靠异质结构波导：中间有效折射率较高，上下包层折射率较低，光被限制在有源区附近。

横向方向常靠 ridge waveguide 或 buried heterostructure：中间通道的有效折射率和电流注入条件不同，模式更愿意集中在指定路径。

## 载流子约束：为什么需要量子阱

上一节讲的是**光的约束**——把光模场限制在有源区附近。但激光器还需要另一层约束：**把注入的电子和空穴集中在最窄的能量范围内**，让它们高效参与受激辐射。这就涉及态密度和量子阱。

### 态密度：在某个能量附近有多少"座位"

从 k 空间出发。之前讨论过，允许的 k 值是均匀分布在 k 空间中的。态密度的任务是把这均匀的分布翻译成"在某个能量 E 附近有多少个电子状态"。

由于 E 和 k 的关系不是线性的（E ∝ k²），翻译后在能量轴上就不均匀了。三维体材料中，等能面是一个半径为 k 的球（E = ℏ²k²/2m*）。能量越高，球越大，包住的状态越多——态密度随 √E 增长：

```
态密度 g(E) ↑
            │                    ╱
            │                  ╱
            │                ╱    三维体材料（√E）
            │              ╱
            │            ╱
            │          ╱
            │        ╱
            │      ╱
            │    ╱
            │  ╱
            │╱
            └────────────────→ E
            E_c（导带底处，态密度 → 0）
```

问题在于：在导带底处，态密度趋近于零。电子被注入导带后，在导带底附近找不到足够的状态坐，被迫占据更高能量的状态——而这些"高位"状态对应的跃迁能量偏离带隙，对增益没有直接贡献，白白浪费了注入。

### 量子阱：限制一维，态密度变台阶

将材料厚度压缩到德布罗意波长量级（~10 nm），电子在这个方向上的 k 不再连续，被量子化为有限个分立值（k_z1, k_z2, ...），每个对应一个**子带**。剩下的两个平面方向电子仍然自由移动。

二维 k 空间中等能面是圆而非球，每个子带的态密度是**常数**：

```
态密度 g(E) ↑
            │           ┌──── 子带3
            │           │
            │      ┌────┤
            │      │    │        量子阱（阶梯状）
            │ ┌────┤    │
            │ │    │    │
            │ │子带2│    │
            │ │    │    │
            │ │子带1│    │
            └─┴────┴────┴──→ E
             E₁   E₂   E₃
```

第一个子带从 E₁ 起就提供恒定的非零态密度——电子"一进门就有座"，集中在导带底附近，高效参与受激辐射。相比体材料需要"爬坡"找状态，量子阱将注入载流子"聚拢"在可利用的能量窗口内。

| | 体材料（3D） | 量子阱（2D） |
|---|---|---|
| 态密度形状 | √E，渐增 | 阶梯，每子带恒定 |
| 导带底处 | 态密度 → 0 | 从 E₁ 起就有恒定非零态密度 |
| 注入效率 | 电子分散在能量轴上 | 电子集中在导带底附近 |
| 阈值电流 | 更高 | 更低 |
| T₀ | 更低（~55-65 K） | 更高（可 >100 K） |

### 量子限域的物理图景

每减少一个维度，态密度就被"聚拢"一次：

```
3D 体：╱       →  电子分散在能量轴上
2D 阱：阶梯     →  电子被聚拢到子带边缘
1D 线：锯齿峰   →  电子被聚拢到更窄的能量范围
0D 点：竖线     →  电子只有几个分离的能级，像单个原子
```

量子阱（2D）是集成光子学中最成熟的选择——它能显著改善阈值电流和温度敏感性，且制造工艺（外延生长）可控。MQW（多量子阱）结构通过堆叠多个量子阱，在增加总增益的同时保持态密度优势。

## Engineering Implementation

设计目标是让三件事重叠：

- 注入载流子的区域。
- 提供增益的 active region。
- 被腔体选中的 optical mode。

如果重叠不好，结果可能是阈值升高、效率下降、热点增加、模式不稳定或良率下降。

典型结构取舍：

- Ridge waveguide：制造相对简单，性能和成本平衡。
- Buried heterostructure：约束更强，但工艺更复杂。
- MQW / SCH：把载流子和光场限制到更薄更有效的区域。

## Key Metrics

- confinement factor。
- mode overlap。
- ridge width。
- active-region thickness。
- current leakage。
- transverse mode stability。
- thermal resistance。

## Common Misconceptions

- 激光定向不是单次复合事件决定的。
- 光不是只在有源层里传播，模场会延伸到包层和附近材料。
- 更强约束不总是免费收益，工艺复杂度、散射、热和良率都会变化。

## Short Version

半导体激光器把光限制在三维结构里：纵向靠腔体反馈，垂直靠异质结构波导，横向靠脊形或掩埋结构。方向性是模式被筛选和放大的结果。

## One-Sentence Answer

TFLN（thin-film lithium niobate，薄膜铌酸锂）利用 Pockels 效应实现亚纳秒级电光切换；将 MZI 单元级联成光交换矩阵，由集群调度器驱动，就能在数据中心里按需重构 GPU 之间的光路拓扑。这条链路的每一层（材料 → 器件 → 控制面 → 系统）都有各自的瓶颈和取舍。

## Why This Exists

AI 集群的 GPU 之间需要巨大的东西向带宽。随着铜互连逼近物理极限，光互连正从模块级向系统级渗透。TFLN 作为光开关平台受到关注，是因为它同时满足高速切换、低静态功耗、无活动部件和 CMOS 兼容驱动电压，而 MEMS 和硅光热光开关各自有致命短板。

## Prerequisites

- 干涉、谐振与损耗（MZI 依靠干涉工作）
- 折射率与全内反射（波导基础）
- LNOI and TFLN（材料平台层面的背景）
- 电信号到光信号的链路总览

## Physical Principle

### TFLN 的 Pockels 效应

铌酸锂（LiNbO₃）具有强电光效应。外加电场改变材料折射率，进而改变通过波导的光的相位。TFLN 把这个能力从厘米级体材料压到亚微米薄膜，r₃₃ 约 30 pm/V，调制带宽可超过 100 GHz。

光相位变化 Δφ 由外加电压 V 控制：

```
Δφ = (π × L × n³ × r₃₃ × V) / (λ × d)

L  = 电极长度
n  = 铌酸锂折射率
r₃₃ = Pockels 系数
λ  = 光波长
d  = 电极间距
```

当电极长度和间距确定后，Δφ 与外加电压成正比。

### MZI 光开关：从一束光到两个出口

一个 Mach-Zehnder 干涉仪（MZI）光开关由四个部分构成：

```
输入 3dB 耦合器 → 上臂（TFLN 电极）→ 输出 3dB 耦合器 → Bar 口
                → 下臂             →                 → Cross 口
```

光经过 MZI 并不做选择。整个过程分三步：

**第一步：分光。** 输入端的 3dB 耦合器把一束光劈成两束相干复制品，各拿原光一半能量。分光时交叉路径比直通路径多产生 90° 的固定相移。

**第二步：调相。** TFLN 电极只在上臂施加额外相移 φ。下臂保持原相位。两臂到达输出耦合器时相对相位差为 (φ - 90°)。

**第三步：合光干涉。** 输出端耦合器的两个波导靠得足够近（间距几百纳米），光场尾部的倏逝波互相泄漏。两束光在耦合区重叠后，整个区域形成一个统一的电磁系统——超模（supermodes）。相对相位差决定了系统激发的是对称超模还是反对称超模，从而预先决定了能量流向哪个出口。

两个出口的功率分配：

```
P_bar   = P_in × sin²(φ/2)
P_cross = P_in × cos²(φ/2)
```

| φ 的值 | sin²(φ/2) | cos²(φ/2) | 光从哪出？ |
|--------|-----------|-----------|----------|
| 0（不加压） | 0 | 1 | 全部走 Cross |
| π（加 V_π） | 1 | 0 | 全部走 Bar |
| π/2（半压） | 0.5 | 0.5 | 各一半 |

V_π 约 2-3V。一个 digital 电信号（加不加 V_π）直接决定出口。电压定了，路径就定了。多个 2×2 MZI 按 Benes 或 Clos 拓扑级联，可以构成 N×N 无阻塞光交换矩阵。

### TFLN 的非调制能力

除调制和开关外，TFLN 在同一平台上还拥有：

- **χ² 非线性**：支持倍频（SHG）、差频（DFG）、光参量振荡（OPO），用于波长转换和可调谐光源。
- **压电效应**：支持声光调制器、SAW/BAW 滤波器，可在 RF 前端处理信号。
- **自发参量下转换（SPDC）**：产生纠缠光子对，是量子光子学集成化的重要路径。
- **克尔孤子频梳**：在微环谐振器中产生等间距多波长梳齿，可当 WDM 光源用。

这些能力的共同基础是：TFLN 是唯一在同一平台上同时拥有强电光效应、强 χ² 非线性、压电效应和超低损耗波导的材料。

## Engineering Implementation

### 控制信号从哪来

TFLN 电极上的电压不是凭空产生的。控制面分三层：

```
集群调度器（软件）       "GPU0 需要跟 GPU7 做 AllReduce，搭光路"
        │
        ▼
SDN 光网络控制器         路径计算：GPU0 → MZI₁₂ → MZI₃₇ → GPU7
        │                生成沿途每个 MZI 的配置
        ▼
驱动芯片（DAC + 运放）    数字指令 → 精确模拟电压（0 或 V_π）
        │
        ▼
TFLN 电极                金/铝电极，几十微米长，电场建立 <1 ns
```

各层耗时：

| 步骤 | 典型耗时 |
|------|---------|
| 调度器检测通信模式、决策 | ~10 μs |
| SDN 控制器计算路径 | ~1 μs |
| 控制包下发到驱动芯片 | ~1 μs |
| DAC 锁存电压 | ~5 ns |
| TFLN 电极充电 | `<1 ns` |
| **总延迟** | **~12 μs** |

TFLN 自身的切换时间（亚纳秒）仅占总延迟的 0.01%，瓶颈在电子控制面。

### 调度器为什么不是瓶颈

光电路交换（OCS）和电交换机的控制面负载完全不同：

| | 电交换机 | OCS |
|--|---------|-----|
| 调度粒度 | 逐包（纳秒级） | 逐作业/逐训练 step（微秒到毫秒级） |
| 路径维持 | 包走完就拆 | 保持到作业结束 |
| 每秒决策次数 | 数十亿 | 几百到几千 |
| 调度器负载 | 必须硬件加速（TCAM/ASIC） | 一个 ARM 核即可 |

OCS 是电路交换，光路一旦建立就固定下来直到作业结束。调度器只在建立和拆除时介入，所以不是瓶颈。

### 调度器什么时候会出问题

当重配置频率提高时，瓶颈会从调度器自身转移到另外三个维度：

- **光路冲突**：两条光路不能同时占用同一个输出端口。GPU 越多，冲突概率越高。
- **拓扑搜索复杂度**：在大规模矩阵里找到无冲突的多条同时光路，本质是 NP-hard 的图着色问题。
- **光路建立开销**：即使开关在纳秒内切换，激光器重锁定和接收端 CDR 重同步仍需微秒级时间。切换太频繁会导致有效带宽下降。

解决方案是把调度分层：集群级调度器（分钟级，只管作业的起停和资源分配），作业级调度器（微秒-毫秒级，只管理作业内部几十个 GPU 的局部光路），必要时预计算多套拓扑，step 之间直接切而不临时算。

### OCS 在数据中心的具体场景

**大模型训练的 AllReduce 加速。** 训练中 GPU 通过 ring 结构做梯度同步。当某对 GPU 之间流量暴增时，固定 ring 路径形成瓶颈。OCS 可以为这对 GPU 建立直连光路，跳数减为 1，有效带宽翻倍。

**MoE 模型的 Expert 路由。** MoE（Mixture of Experts）中每个 token 路由到不同 expert GPU。同一批 token 的 expert 分布在每次迭代中都不同。MEMS OCS 的毫秒级切换来不及逐 batch 重建拓扑；TFLN 的纳秒级切换可以在逐 step 甚至逐 token 粒度上重配光路。

**内存解耦（Memory Disaggregation）。** 未来趋势是把 HBM 内存池从 GPU 中拆出，多 GPU 共享远程内存。OCS 按需把任意 GPU 连到任意内存池——哪个 GPU 需要大带宽，开关在纳秒内把它连到空闲内存池，不用了立即释放。

**故障恢复。** 光纤断裂或交换机宕机时，传统电交换网络的控制面需要几十到上百毫秒重新计算路由。OCS 可以在纳秒级配置备用光路，上层作业几乎无感。

### 三种光开关方案对比

| 维度 | MEMS 微镜 | SiPh 热光 | TFLN 电光 |
|------|----------|----------|----------|
| 切换速度 | 1-10 ms | 1-10 μs | `<1 ns` |
| 驱动方式 | 机械微镜转动 | 加热波导 | 施加电场 |
| 静态功耗 | 低（保持不用电） | 高（持续加热，每单元数十毫瓦） | 近乎零（纯电场，无电流） |
| 驱动电压 | 需高压 | 需持续电流 | 2-3V，可与 CMOS 共轨 |
| 活动部件 | 有（镜子会疲劳磨损） | 无 | 无 |
| 可集成性 | 分立 | 单片集成 | 可异质集成到 SiPh |
| 光谱范围 | 宽 | 中等 | 极宽（400nm-5μm） |

TFLN 是唯一在速度、功耗、可靠性和可集成性四条线上同时得分的平台。MEMS 怕磨损，SiPh 热光怕耗电，TFLN 两样都没粘上。快只是附送的。

## Key Metrics

- V_π（半波电压）：TFLN 典型 2-3V
- V_π·L（调制效率-长度积）：越小越好，决定器件紧凑度
- 调制带宽：TFLN >100 GHz（实验室可到 500 GHz+）
- 插入损耗：包含耦合器分光损耗和波导传播损耗
- 光传播损耗：TFLN 波导可低至 `<0.1 dB/cm`
- 切换时间：TFLN 电极充电 `<1 ns`
- 静态功耗：TFLN 近乎零
- 端口数 × 消光比：决定交换矩阵规模和串扰
- 光路建立总延迟（含控制面）：~12 μs

## Common Misconceptions

- 光在经过 MZI 耦合区时并不是先分叉再选择。两个输出口在耦合区里不是独立的路径——整个耦合区是一个统一的电磁系统，相位差预决定了能量分配到哪个超模，从而决定了出口。
- TFLN 的亚纳秒切换速度在当前的 OCS 架构里并没有被用满。瓶颈在控制面的决策延迟和光路建立开销，不在开关物理速度。
- TFLN 的优势不是单一维度的"快"。而是速度 + 功耗 + 可靠性 + 可集成性的综合得分。MEMS 和 SiPh 热光各自在某一个维度上有致命弱点。
- OCS 的调度器在作业级粗粒度使用模式下不是瓶颈。到微秒级逐包光交换时，瓶颈转移到路径冲突和拓扑搜索复杂度上，TFLN 只保证物理层不拖后腿。
- TFLN 不提供高效原生通信光源，所以不能消除对 InP 或 GaAs 光源的需求。它解决的是调制和开关问题，不解决增益问题。

## Short Version

TFLN 用 Pockels 效应在亚纳秒内改变光的相位。一个 MZI 单元通过分束→调相→干涉→合束，把相位差转化为对出口的选择——这不是光的主动选择，而是耦合区超模决定了能量流向。MZI 级联成 N×N 矩阵后，由集群调度器通过 SDN 控制器和驱动芯片下发电压指令。在 OCS 模式下，调度器本身不是瓶颈；真正制约大规模光交换的是光路冲突、拓扑搜索复杂度和光路建立开销。TFLN 的真正优势不是单一维度的快，而是速度、功耗、可靠性和可集成性同时得分的综合平台能力。

## 一、CoPoS 定义与架构总览

### 1.1 命名中的范式转移

CoPoS（Chip-on-Panel-on-Substrate）这个名字本身就是宣言。与 CoWoS（Chip-on-Wafer-on-Substrate）相比，只改了一个词：**Wafer → Panel**。这一字之差代表了先进封装四十年来最根本的形态变革——从圆形晶圆走向矩形面板。

CoPoS 不是对 CoWoS 的渐进改进，而是一次基础架构的重构。核心变化包括：

| 维度 | CoWoS 时代 | CoPoS 时代 |
|------|-----------|-----------|
| 载具形状 | 圆形 300mm 晶圆 | 矩形玻璃面板 |
| 核心材料 | 硅中介层（CoWoS-S）或有机 + Si bridge（CoWoS-L） | 玻璃核心载板 + ABF 增层 |
| 面积利用率 | ~65%（晶圆边缘浪费约 35%） | >95% |
| Via 技术 | TSV（硅通孔） | TGV（玻璃通孔） |
| 最大封装尺寸 | 5.5x reticle（~4720mm²） | 9.5x reticle（~7890mm²），未来可达 14x+ |
| 量产时间 | 已量产 | 目标 2028 H2 |

### 1.2 完整架构堆叠图

CoPoS 封装从底到顶依次为：

```
  ┌─────────────────────────────────────────────┐
  │  Chiplet（GPU / HBM / I/O Die）              │
  │  [微凸块 micro-bump 连接至 ABF 表面]         │
  ├─────────────────────────────────────────────┤
  │  ABF 增层（顶部）                             │
  │  - Cu 精细布线，L/S 8-12μm                   │
  │  - 2-4 层介质层，每层 ~15-25μm              │
  │  - 激光钻孔微通道 ~30-60μm                  │
  ├─────────────────────────────────────────────┤
  │  玻璃核心载板（Glass Core Substrate）         │
  │  - TGV 铜填充垂直互连                         │
  │  - 最终厚度 ~100-200μm                       │
  ├─────────────────────────────────────────────┤
  │  ABF 增层（底部）                             │
  │  - TGV-to-基板布线                           │
  │  - BGA 焊盘阵列                              │
  ├─────────────────────────────────────────────┤
  │  封装基板（IC Substrate / PCB 层压板）        │
  ├─────────────────────────────────────────────┤
  │  BGA 锡球                                    │
  └─────────────────────────────────────────────┘
```

### 1.3 架构要点

理解 CoPoS 架构需要先纠正三个常见误解（详见第六章）：

1. **玻璃不是中介层。** 互连功能被拆分到三个层面：芯片侧的 RDL（细线宽）、玻璃核心的 TGV（垂直互连）、ABF 增层（面内布线）。玻璃核心的角色是机械支撑和 CTE 匹配平台，而非信号路由中介层。
2. **玻璃不取代 ABF。** 玻璃与 ABF 以三明治结构共存——ABF 增层覆盖在玻璃核心的上下两面，构成 ABF-GCP（ABF Glass Core Package）。
3. **芯片不直接贴在玻璃上。** Die 贴装在玻璃顶部的 ABF 增层表面，而非玻璃表面。

### 1.4 CoPoS vs. CoWoS：逐项对比

| 参数 | CoWoS（当前） | CoPoS（下一代） |
|------|-------------|----------------|
| 全称 | Chip-on-Wafer-on-Substrate | Chip-on-Panel-on-Substrate |
| 核心材料 | 硅中介层（CoWoS-S）或 LSI bridge + 有机 RDL（CoWoS-L） | 玻璃核心 + ABF 增层（ABF-GCP） |
| 形状 | 圆形 300mm 晶圆 | 矩形面板 |
| 初始面板尺寸 | 不适用（晶圆基） | 310×310mm（中试），510×515mm（HVM） |
| 未来面板尺寸 | 不适用 | 750×620mm |
| 面积利用率 | ~65%（晶圆边缘浪费） | >95% |
| Via 技术 | TSV（硅通孔） | TGV（玻璃通孔） |
| 最大深宽比 | ~10:1（TSV） | ~50:1（TGV，已验证） |
| RDL L/S | 1.5-2μm（CoWoS-L） | 2-5μm（ABF 增层） |
| 核心 CTE | ~2.6 ppm/°C（Si） | ~3-9 ppm/°C（玻璃可调） |
| 介电损耗 | 中等（硅为半导体，有损耗） | 极低（玻璃为绝缘体） |
| 目标封装尺寸 | 最高 5.5x reticle（~4720mm²） | 9.5x reticle（~7890mm²）及以上 |
| 量产状态 | 量产中 | 目标 2028 H2 |
| 相对成本 | 最高（复杂硅中介层） | 中等（比 CoWoS-L 低 15-25%） |

## 二、玻璃核心载板的材料逻辑

### 2.1 为什么是玻璃，而不是硅或有机？

先进封装发展到今天，"材料天花板"正在成为制约封装尺寸扩大的主要瓶颈。三种候选材料的核心物性对比揭示了选择玻璃的理由：

**CTE 匹配表：**

| 材料 | CTE（ppm/°C） | 杨氏模量（GPa） | 热导率（W/m·K） |
|------|--------------|----------------|----------------|
| 硅（Si） | 2.6-3.0 | 130-185 | 148 |
| 硼硅玻璃 | 3.2-5.0 | 50-90 | 1-2 |
| 铝硼硅玻璃 | 3.2-7.2 | 60-80 | 1.0-1.5 |
| 有机 ABF | 14-70 | 0.1-2.0 | 0.3-1.0 |
| 铜（Cu） | 16.5 | 110-128 | 401 |

**关键结论：** 有机基板（ABF / BT / FR-4）的 CTE 为 14-70 ppm/°C，与芯片（硅，2.6-3.0 ppm/°C）之间存在 **5-25 倍** 的 CTE 失配。当封装尺寸超过 100×100mm、功耗超过 1000W 时，这种失配会导致严重的翘曲（即业界所说的"warpage wall"）、热机械应力以及焊点可靠性失效。玻璃的 CTE（3-5 ppm/°C）与硅基本匹配，从根本上消除了这一扩展瓶颈。

### 2.2 玻璃的电学优势

玻璃是绝缘体，而硅是半导体——这一本质差异在高频信号传输中至关重要：

| 电学参数 | 玻璃 | 硅 | ABF |
|---------|------|----|-----|
| Dk（介电常数） | ~4-6 | ~12 | ~3-4 |
| Df（损耗角正切） | 0.003-0.005 | ~0.1（RF 下） | 0.01-0.02 |
| 体电阻率 | >10¹⁴ Ω·cm | ~10³ Ω·cm | >10¹⁴ Ω·cm |
| 信号损耗（相对） | 基准（最低） | 高（硅为半导体） | 中 |

用硅做中介层，信号在硅中传输时会产生衬底损耗和串扰。玻璃的本征绝缘特性消除了这一问题，高频信号损耗比 ABF 降低 40-67%，并支持 >100GHz 的毫米波 / 6G 应用。

### 2.3 玻璃的平整度优势

玻璃核心载板是实现细线宽光刻的关键前提：

- **表面粗糙度 Ra < 0.5nm**（原子级平整），而有机基板的平整度差 1-2 个数量级
- 超高平整度使得 sub-2μm L/S 的精细光刻成为可能
- 熔融下拉法（fusion draw）制造的玻璃可实现极低的总厚度偏差（TTV），这对 TGV 的均匀加工至关重要
- 玻璃的刚度-重量比优于有机核心，在热循环中大幅减少面板翘曲

### 2.4 玻璃当前的技术局限

CoPoS 选择玻璃并非没有代价。玻璃作为封装材料仍面临若干根本性挑战：

| 挑战 | 影响 | 缓解方案 |
|------|------|---------|
| **脆性** | 裂纹扩展、边缘崩边（尤其在搬运过程中） | 激光倒角、边缘强化、优化搬运系统 |
| **TGV 加工困难** | 玻璃硬且脆，传统机械钻孔不适用 | LISE 激光诱导选择性刻蚀、ECDM 电化学放电加工 |
| **金属-玻璃附着** | Cu 在玻璃表面附着力差，易分层 | 附着力层（Ti、Ni-P、Ru）、硅烷化处理 |
| **成本** | 目前是 ABF 基板的 2-3 倍 | 产能规模扩大后成本下降 |
| **良率** | 当前 ~75-85%，远低于有机基板的 95%+ | 通过 2027-2028 年的工艺成熟度提升 |
| **供应链** | 合格的玻璃及加工设备供应商有限 | Corning、SCHOTT、AGC、Absolics 快速扩产 |

### 2.5 玻璃的热管理与 CPO 潜力

虽然玻璃的热导率低（1-2 W/m·K），仅为硅（148 W/m·K）的 1% 左右，但这对 CoPoS 并非致命问题：

- **主散热路径纵向：** 芯片→TIM→散热器（通过芯片顶部直接冷却），而非横向穿过玻璃核心
- **玻璃核心厚度薄：** 最终产品中仅 100-200μm，热阻可控
- **光学透明性：** 玻璃在可见光到近红外波段透明，可通过离子交换在玻璃内部嵌入波导，损耗低至 0.05-0.1 dB/cm——这意味着玻璃核心载板天然适配 **共封装光学（CPO）** 集成，是硅中介层无法提供的独特优势

## 三、两种玻璃的彻底区分（全文最关键的知识点）

CoPoS 中使用两种功能完全不同的玻璃组件，将它们混为一谈是理解 CoPoS 架构的最大障碍。

### 3.1 临时玻璃载具 vs. 玻璃核心载板

| 维度 | 临时玻璃载具 | 玻璃核心载板（量产面板） | 玻璃核心载板（单品） |
|------|-------------|----------------------|-------------------|
| **功能** | 制程工具——提供刚性支撑 | 结构材料——进入最终产品 | 结构件——封装核心层 |
| **材质** | 硼硅 / 铝硼硅玻璃 | 封装级玻璃（定制配方） | 同左 |
| **尺寸** | 310×310mm | 510×515mm（HVM） | 按产品定（如 ~100×150mm） |
| **是否进入最终产品** | ❌ 否，加工完成后剥离 | ✅ 是，切割为单品 | ✅ 是 |
| **关键工艺** | 临时键合 → 加工 → 激光解键合 | TGV 成型 → 填铜 → ABF 双面覆层 → 切割 | 已包含在面板级加工中 |
| **重复使用** | 可重复 3-10 次 | 不重复使用 | 不重复使用 |
| **供应商** | Corning、SCHOTT | Corning、SCHOTT、AGC、Absolics | 同左 |
| **供货历史** | 显示行业成熟供货 | 半导体封装新兴品类 | 同左 |

### 3.2 临时玻璃载具的角色

临时玻璃载具本质上是一块**高平整度的工艺辅助工具**，在整个流程中扮演"移动工作台"的角色：

1. 在 ABF 压合、RDL 增层等前段工艺中提供刚性支撑
2. 要求在 UV 到 IR 波段具有高透光率（支持激光解键合）
3. CTE 需与工艺温度匹配（3.2-10 ppm/K）
4. 表面要求原子级洁净（无缺陷，避免颗粒污染工艺）
5. 通过临时键合胶（激光可分解或热滑移型）与面板结合
6. 加工完成后通过激光剥离（LLO）、氙灯闪光键合（Resonac 方案）或热滑移方式去除
7. 去除后经表面处理可重复使用 3-10 次

### 3.3 玻璃核心载板的角色

玻璃核心载板是**最终封装产品的组成部分**，是整个 CoPoS 架构的"骨架"：

1. 在 510×515mm（或更大）的面板上进行 TGV 加工
2. TGV 填铜后，双面覆 ABF 增层
3. 从面板切割为单颗封装的核心基板（尺寸根据产品不同，如大型 AI 封装约 100×150mm）
4. 玻璃最终厚度约 100-200μm（从初始 400-800μm 减薄而来）
5. 进入最终产品后起到 CTE 匹配平台 + 机械支撑 + 垂直互连的三重作用

### 3.4 含玻璃载具的完整工艺流程图

```
  1. 玻璃面板 510×515mm（核心载板材料）
     │
     v
  2. TGV 成孔（LISE 激光诱导选择性刻蚀）
     │
     v
  3. 功能层沉积（附着层 + 种子层）
     │
     v
  4. Cu 电镀（无空洞 TGV 填充）
     │
     v
  5. 顶部 ABF 压合 + Cu 增层
     │
     v
  6. 临时键合至玻璃载具 310×310mm（施加临时键合胶）
     │
     v
  7. 背部减薄 + 底部 ABF 压合
     │
     v
  8. 激光解键合（从玻璃载具剥离）
     │
     v
  9. 切割为单颗玻璃核心基板
     │
     v
  10. 芯片贴装 + IC 基板键合
```

将两种玻璃混为一谈会导致严重误解——这正是业界早期报道中频繁出现概念错误的原因。

## 四、TGV（Through-Glass Via）技术

<TermNote label="TGV" note="Through-Glass Via，玻璃通孔。在玻璃基板上制作垂直导电通孔的工艺，功能类似硅中介层的 TSV，但加工方式完全不同——玻璃是非晶脆性材料，不能像硅一样用 DRIE 刻蚀" />

### 4.1 TGV vs. TSV：全面对比

| 参数 | TSV（硅通孔） | TGV（玻璃通孔） |
|------|--------------|----------------|
| 衬底材料 | 晶体硅 | 非晶玻璃 |
| 成孔方式 | DRIE（Bosch 工艺） | LISE、ECDM 或机械 |
| 量产深宽比 | ~10:1 | ~50:1（已验证） |
| 侧壁形貌 | 垂直、锯齿状（scalloped） | 锥形（5-15° 倾角） |
| 量产最小直径 | ~5-10μm | ~10-50μm |
| 绝缘方式 | SiO₂ CVD 沉积 | 玻璃本征绝缘 |
| 衬底损耗 | 中等（硅在 RF 下损耗大） | 极低（玻璃为电介质） |
| 相对成本 | 高（DRIE 设备昂贵） | 较低（激光曝光后湿法刻蚀） |

**核心差异：** TSV 依赖 DRIE 对晶体硅的各向异性刻蚀；TGV 则利用激光改性后选择性湿法刻蚀。玻璃的通孔深宽比可达 50:1，远超 TSV 的 10:1，这对高密度垂直互连是巨大优势。

TGV 基板市场 2022 年估值约 6000 万美元，预计 2029 年达 4.805 亿美元（CAGR 34.2%）。

### 4.2 LISE 成孔工艺（主流方案）

LISE（Laser-Induced Selective Etching，激光诱导选择性刻蚀）是目前最主流的 TGV 成孔方法，分为三个步骤：

**步骤一：飞秒激光改性**
- 超短脉冲激光（飞秒至皮秒级，典型 1030nm，<10ps 脉宽）聚焦在玻璃表面
- 通过非线性吸收在光束路径上形成纳米衍射光栅结构（nanocraters）
- 单脉冲 ps 激光 + 10% KOH 85°C 5 小时可在熔融石英上形成 TGV
- 脉冲间隔 1-2μs 产生的热积累会阻止选择性刻蚀
- **3-5000μs 间隔**可产生规整的纳米衍射光栅
- 超过 5000μs 则结构不连续

**步骤二：纳米光栅形成**
- 双脉冲方案（213ps + 10ns 间隔）可增加电子动能
- 实现最深 22.39μm 的 TGV，光栅周期 156nm
- 光栅区域的化学活性显著提高，为后续湿法刻蚀创造选择性

**步骤三：选择性湿法刻蚀**
- 激光改性区域的刻蚀速率是未改性区域的 **10-100 倍**
- 刻蚀液：稀 HF（3-10%）或 KOH 85°C
- HF 浓度从 10% 降至 3%，TGV 侧壁角从 80.65° 增至 84.18°（更陡直，有利于后续金属化）
- 可实现 TGV 直径 10-50μm，深宽比高达 50:1

### 4.3 ECDM 备选工艺

ECDM（Electrochemical Discharge Machining，电化学放电加工）是一种备选 TGV 成孔方式，通过高电压放电局部降低玻璃粘度并焦耳热排出材料：

- 多尖电极（2×5 和 2×2 阵列）：顶/底直径 580/286μm，实现螺旋和环面 3D 电感，电阻 338 和 168 mΩ
- 电解液优化：在 KOH 中添加聚丙烯酰胺（NTF），过切标准差从 9.79μm 降至 3.34μm，热影响区缩小 64.81%
- CNT 增强电极：材料去除率提升 80%，表面粗糙度降低 67%
- 激光辅助 ECDM：Nd:YVO₄ 激光（1064nm，12ps）+ ECDM（NaOH 电解液），将通孔剖面从 V 形转变为 U 形
- 低温电极冷却（液氮 -185°C）：钨电极磨损降低 58%，铜电极降低 35%

### 4.4 TGV 填铜流程

TGV 的金属化是决定电气性能的关键步骤，涉及三层功能膜：

**第一层：绝缘层**
- 通常为 PECVD SiO₂
- 不过玻璃的本征电阻率 >10¹⁴ Ω·cm 在某些应用中可能已足够
- 主要目的是防止 Cu 离子扩散到玻璃中

**第二层：附着层（附着力是最大难点）**

Cu 在玻璃表面的附着力极差（玻璃表面惰性高），业界已发展出多种附着方案：

| 方法 | 描述 | 适用性 | 局限 |
|------|------|--------|------|
| 溅射 Ti/Cr/TiW | 业界标准物理气相沉积 | 低深宽比 TGV | 高深宽比步进覆盖率差 |
| 化学镀 Ni-P | 10:1 通孔中均匀镀 ~200nm | 中深宽比 | >400°C 氧化增阻 |
| 溶液基氧化物促进剂 | 旋涂 + 化学镀 Cu | 高深宽比 | 工艺窗口窄 |
| 直接湿法镀 Cu | 超声清洗 + UV 活化，无需附着层 | 中深宽比 | 附着力 ~0.35 kN/m |
| ALD Ru 薄膜 | 原子层沉积 Ru | 深宽比 10-20 | 产能低 |

**第三层：种子层 + 电镀**
- 种子层：导电基底（Cu、Ni-P 或 Ru）
- PVD 溅射在高深宽比 TGV 中的步进覆盖率差——化学镀液沉积正成为主流选择

**电镀添加剂体系：**

Cu 电镀使用三类添加剂（与 TSV 铜镶嵌工艺类似）：

- **抑制剂（Suppressor）：** PEG、PVP、NBT/NTBC——抑制通孔开口处沉积，防止早期封口
- **加速剂（Accelerator）：** SPS——促进通孔底部沉积
- **整平剂（Leveler）：** Janus Green B、PVP（根据分子量兼有抑制和整平作用）

**优化结果：** 抑制剂:加速剂:整平剂 比例 50:1:1.25 可在 150μm 深锥形通孔（顶径 50μm、底径 20μm）中实现 2.25 小时无空洞填充（电流密度 1 ASD）。比例 60:1:1 可在 1.5 ASD 条件下 1.5 小时完成无空洞填充。

**PVP 分子量效应：**
- 小分子量 PVP（10,000 g/mol）形成更致密的抑制层，实现无缺陷填充
- 大分子量 PVP（360,000 g/mol）形成的抑制层密度较低，允许加速剂进入，效果较差

**周期性脉冲反镀（PPR）：**
PPR 波形交替施加正向脉冲（阴极 Cu 沉积）、反向脉冲（阳极溶解，通孔开口处 Cu 更薄、底部更厚）和关断脉冲（Cu 离子扩散平衡浓度梯度）。锥形通孔在 5.85 mA/cm² 条件下可实现 100% Cu 填充。三级 PPR（低密度保形 → 中密度超保形 → 高密度完全填充）可最大限度减少缺陷并缩短加工时间。

**SiO₂ 阻挡层（SBL）降低 Cu 过镀：**
在 Cu 填充前于顶/底表面沉积 200-500nm SiO₂（PECVD），可抑制平坦表面上的 Cu 过镀，减少后续 CMP 工作量，实现无空洞填充并降低后镀加工成本。

### 4.5 TGV 的热机械可靠性

CTE 失配（Cu 17 ppm/°C vs. 玻璃 3-9 ppm/°C）在热循环中产生应力：

| 状态 | 应力类型 | 危害程度 | 说明 |
|------|---------|---------|------|
| 加热 | Cu 膨胀 > 玻璃 → 径向拉应力 | 较低 | 裂纹趋向自限 |
| 冷却 | Cu 收缩 > 玻璃 → 周向拉应力 | **高** | 导致界面分层和电气失效 |

**缓解措施：**
- 聚合物填充 TGV 吸收应力
- 锥形通孔设计减少应力集中
- 退火工艺稳定 Cu 微结构

## 五、ABF-GCP（ABF Glass Core Package）架构

### 5.1 ABF 材料概述

<TermNote label="ABF" note="Ajinomoto Build-up Film，味之素增层薄膜。日本味之素旗下 Ajinomoto Fine-Techno 开发的环氧基介电薄膜，是 FC-BGA 基板的标准增层介质材料。" />

ABF 的关键物性参数：

| 参数 | 值 |
|------|-----|
| Dk（介电常数） | 3.4-3.8 |
| Df（损耗角正切） | 0.01-0.02 |
| CTE（< Tg） | 14-30 ppm/°C |
| CTE（> Tg） | 70-100 ppm/°C |
| 杨氏模量 | 3-8 GPa |
| Tg（玻璃转化温度） | 160-200°C |
| 量产最小 L/S | ~8-10μm（可推进至 2-5μm） |
| 工艺 | 真空压合 + 光刻 + Cu SAP |

### 5.2 ABF-GCP 架构详解

在 CoPoS 中，ABF 与玻璃构成复合封装体。玻璃核心提供机械稳定性和 CTE 匹配，ABF 层提供双面的精细布线能力：

**顶部 ABF 增层（芯片侧）：**
- 2-4 层介电层，每层 ~15-25μm
- 激光钻孔微通道，直径 ~30-60μm
- Cu 细线 8-12μm L/S
- 芯片贴装表面

**玻璃核心层：**
- 初始厚度 400-800μm
- 最终减薄至 <100-200μm
- TGV 提供 Z 轴互连

**底部 ABF 增层（基板侧）：**
- 2-4 层介电层（与顶部对称）
- BGA 焊盘阵列

### 5.3 为什么用玻璃 + ABF，而非只用玻璃？

| 需求 | ABF 的贡献 | 玻璃的贡献 |
|------|-----------|-----------|
| 精细布线 | 成熟 8-12μm L/S 能力 | 提供平整刚性基座支持光刻 |
| 介电性能 | 成熟 RF 材料 | 低 Df 进一步支持 mmWave |
| 机械刚性 | 有限（柔性） | 大面板刚性支撑 |
| CTE 控制 | 高 CTE，单用有问题 | 低 CTE 主导复合材料行为 |
| 工艺成熟度 | 数十年 HVM 经验 | 新兴但可借用显示产业经验 |
| 成本 | 中等（成熟供应链） | 目前为 ABF 的 2-3 倍，预计下降 |

### 5.4 ABF-玻璃三明治结构的应力分析

学术研究（MRS Advances, 2026）表明，玻璃核心双面 ABF 的复合结构会产生复杂的应力分布：

- **室温下：** ABF 在玻璃上处于压缩状态（ABF 固化收缩大于玻璃）
- **高温下：** CTE 失配在 ABF-玻璃界面产生剪切应力
- **热循环中：** 循环应力加速 ABF-玻璃界面裂纹萌生

**缓解方案：**
- ABF-玻璃界面附着促进层
- ABF 层中分布式应力释放结构
- 优化固化曲线减少残余应力

### 5.5 ABF-GCP vs. 竞争对手方案

| 方案 | 核心 | 增层 | 状态 |
|------|------|------|------|
| **ABF-GCP（TSMC CoPoS）** | 玻璃 | ABF（顶部 + 底部） | 研发中（2028 目标） |
| Intel 玻璃基板 | 玻璃 | 专有介质 | HVM（2026） |
| Samsung I-CubeE | 有机面板 | ABF + 嵌入式 Si bridge | 研发中 |
| 传统 FC-BGA | 有机（BT/FR-4） | ABF | 成熟量产 |

## 六、RDL（Redistribution Layer）架构

### 6.1 CoPoS 中的分层互连体系

传统 CoWoS-S 中，所有芯片间和芯片到基板的走线都通过硅中介层的 TSV 和晶圆级 RDL 完成。CoPoS 将这一路由功能拆分为多个层级：

| 路由域 | 技术 | 线宽/间距 | 功能 |
|--------|------|-----------|------|
| **芯片级 RDL** | 晶圆级 Cu/介质 | 1.5-2μm | 芯片 I/O 细间距重分布 |
| **ABF 增层（顶）** | ABF 半加成 Cu | 8-12μm | Die-to-Die 和 Die-to-TGV 路由 |
| **TGV** | 铜填充通孔 | 10-50μm 直径 | Z 轴互连（穿过核心） |
| **ABF 增层（底）** | ABF 半加成 Cu | 8-12μm | TGV 到基板路由 |
| **IC 基板** | 标准层压 | 20-100μm | 最终 BGA 阵列 |

这种分层设计消除了对超高成本硅中介层的需求，同时保持了足够的布线密度。

### 6.2 RDL 技术演进

| 技术代际 | L/S | 应用 |
|---------|-----|------|
| PCB | 60-100μm | 低端、传统 |
| BT 树脂基板 | ~20μm | 中端 |
| ABF 增层 | ~10-12μm | 当前高端 CPU/GPU |
| 晶圆级 RDL | 1.5-2μm | FOWLP、CoWoS-L |
| Damascene RDL | Sub-1μm | 下一代、HBM4+ 集成 |

### 6.3 RDL 集成路线

**A. 硅载板 RDL（CoWoS 级）：**
- RDL 构建在含 TSV（AR ~10:1）的硅中介层上
- 最小厚度：~100μm（硅）
- L/S：~1.5μm（当前最先进）
- 最高的布线密度，最高的成本

**B. 无载板 RDL（FOWLP 级）：**
- RDL 构建在聚酰亚胺/聚合物层上，无硅载板
- 通孔 AR ~1:1（单层 PI ~5-7μm，Cu 通孔 ~7μm）
- 总厚度：~50μm 或更少（取决于层数）
- 成本较低，密度较低

**C. Bridge Die + 最小 RDL（CoWoS-L / CoPoS 兼容）：**
- 嵌入式 Si bridge 实现超密互连（sub-μm L/S）
- 系统级 RDL 仅用 1-2 层粗线
- HBM 集成的最优成本-性能平衡点

### 6.4 芯片侧 vs. 基板侧 RDL

在 CoPoS 中，芯片侧 RDL（在晶圆厂内完成）提供最细间距的重分布。ABF-GCP 增层以较粗的间距完成基板侧路由。这是有意的设计选择——将路由复杂度和成本分配到最合适的工艺层级。

## 七、面板级封装的经济学

### 7.1 什么是 Reticle Limit？

<TermNote label="Reticle" note="光掩模。半导体光刻中使用的石英模板，定义了单次曝光的最大图案面积。标准 reticle 视场为 26×33mm（858mm²），台积电有效面积为 ~830mm²" />

在半导体光刻中，**reticle**（光掩模）是投影芯片图案的石英模板。EUV 光刻机（如 ASML NXE:3400C/3600D）的最大曝光视场定义了 **reticle limit**——单次曝光能加工的最大单片面积。

- 标准 reticle 视场：26×33mm（= 858mm²）
- 台积电有效 reticle 面积：~830mm²

当芯片封装尺寸超过这一限制时，需要 **reticle 拼接**——多次曝光对齐拼合成更大的图案。拼接会引入套刻误差、边缘效应和产能损失。

### 7.2 Retcle 倍数扩展路线图

在先进封装语境中，"Nx reticle" 表示中介层或封装尺寸相对于标准 reticle 视场的倍数：

| 代际 | 倍数 | 约面积 | 封装尺寸（L×W） | 时间线 | 代表产品 |
|------|------|--------|----------------|--------|---------|
| 当前 CoWoS | 3.3-3.5x | ~2830mm² | 100×28mm | 已量产 | AMD MI300X、NVIDIA B200 |
| 下一代 CoWoS | 5.5x | ~4720mm² | 126×37mm | 2026 | NVIDIA Rubin |
| **CoPoS（初始）** | **9.5x** | **~7890mm²** | **160×49mm** | **2028** | **NVIDIA Feynman** |
| CoPoS（未来） | 14x | ~11620mm² | 195×60mm | ~2029 | 下一代 |
| SoW-X | 40x+ | ~33200mm²+ | 300×110mm+ | ~2029+ | 晶圆级 |

**为什么 9.5x 是下一站？** 因为 CoWoS 在 5.5x reticle（~4720mm²）已经逼近极限。NVIDIA Feynman 的 GPU 逻辑 + 12 个 HBM4 堆叠 + LPU + CPU 的总面积需求约 7000-8000mm²，恰好需要 9.5x reticle——这就是 CoPoS 以 9.5x 作为量产目标的直接原因。

### 7.3 面板 vs. 晶圆：面积利用率的降维打击

300mm 晶圆的有效加工直径约 295mm，但圆形边缘会带来大量浪费：

| 参数 | 300mm 晶圆 | 310×310mm 面板 | 510×515mm 面板 |
|------|-----------|----------------|----------------|
| 外形 | 圆形 | 矩形 | 矩形 |
| 总面积 | ~70685mm² | 96100mm² | 262650mm² |
| 有效面积 | ~45000mm²（含边缘浪费） | >91200mm²（>95%） | >249500mm²（>95%） |
| 相对有效面积 | 基准（1x） | ~2.0x | ~5.5x |
| 边缘浪费 | ~35% | <5% | <5% |

**具体到 9.5x reticle 封装（~75×105mm）：**
- 300mm 晶圆上仅能排列 ~1-2 颗
- 310×310mm 面板可排列更多，有效产出具约 1.5x 优势

这就是面板级封装的根本驱动力：当封装面积接近晶圆本身时，"圆"形不再是经济的选择。

### 7.4 CoPoS 的成本结构

| 对比维度 | CoWoS-L | CoPoS（初期） | CoPoS（成熟期） |
|---------|---------|-------------|----------------|
| 中介层/核心材料 | Si bridge + 有机 RDL | 玻璃核心 + ABF 增层 | 玻璃核心 + ABF 增层 |
| 载板形式 | 300mm 晶圆 | 310-510mm 面板 | 510-750mm 面板 |
| 相对成本 | 基准（1x） | -15% 至 -25% | **-40%** |
| 核心成本驱动 | DRIE TSV、CMP、硅晶圆 | LISE TGV、玻璃面板 | 规模效应 + 良率提升 |

成本降低的来源：
1. **玻璃比硅便宜（原料成本低，无需高纯度单晶硅）**
2. **面板面积利用率高（每颗分摊的工艺成本更低）**
3. **LISE 比 DRIE 便宜（湿法刻蚀替代等离子刻蚀，设备投资低）**
4. **省略硅中介层的复杂工艺链（无需 TSV 多次 CMP、Cu 暴露、hybrid bonding）**

### 7.5 面板级封装的优势与挑战

**PLP 的五大优势：**
1. **面积利用率 >95%（vs. 晶圆 ~65%）——更多芯片、更少浪费**
2. **成本优势：UHD fan-out 封装可降低 10-20%（视面板尺寸而定）**
3. **产能提升：更多芯片并行处理，减少换产步骤**
4. **消除 300mm 晶圆直径约束——可制造超大封装**
5. **chiplet 集成：逻辑 + 存储 + I/O + 光子学的规模异构集成**

**PLP 当前挑战：**

| 挑战 | 描述 | 当前状态 |
|------|------|---------|
| 翘曲 | 面板在热应力下弯曲 | 玻璃核心已缓解 |
| 良率 | 缺陷影响比晶圆更大 | 早期良率较低，持续提升中 |
| 设备 | 需要新 CVD/PVD/光刻工具 | 生态快速建设中 |
| 标准化 | 无统一面板尺寸标准 | 310×310mm 成为早期标准 |
| 玻璃脆性 | 微裂纹、边缘完整性 | 激光倒角、强化处理 |
| 检测 | 大面板检测困难 | AOI 系统开发中 |

### 7.6 行业 PLP 现状

| 厂商 | 技术 | 进展 |
|------|------|------|
| **ASE** | 首条自动化 310mm PLP 产线 | 2027 H1 量产；2/2μm L/S；约占台积电后道封装 45%（2026） |

## 八、郭明錤报告三个常见错误的逐条纠正

2026 年 6 月，天风国际分析师郭明錤（Ming-Chi Kuo）发布了关于 CoPoS 的深度报告，其中明确指出市场上流传的三个核心误解。以下是逐条技术解读：

### ❌ 误解一：玻璃是中介层

**错误认知：** 将 CoPoS 中的玻璃核心载板等同于 CoWoS-S 中的硅中介层，认为玻璃承担芯片间的信号路由功能。

**⭕ 正确理解：** 在 CoPoS 架构中，互连功能被拆分到不同物理层：

| 功能 | CoWoS-S | CoPoS |
|------|---------|-------|
| 芯片间精细布线 | 硅中介层 RDL（1.5-2μm） | 芯片侧 RDL（晶圆级） |
| 芯片 I/O 扇出 | 硅中介层 RDL | ABF 增层（8-12μm L/S） |
| 垂直互连 | TSV | TGV（玻璃核心） |
| 芯片到基板扇出 | 硅中介层 + C4 bump | ABF 增层（底部） |

玻璃核心的角色是 **CTE 匹配的刚性支撑平台 + 垂直互连通道**，而非信号路由中介层。芯片间的精细互连由芯片侧 RDL 和 ABF 增层完成。

### ❌ 误解二：玻璃取代 ABF

**错误认知：** 认为玻璃核心载板将取代 ABF（Ajinomoto Build-up Film），玻璃本身就是布线层。

**⭕ 正确理解：** 玻璃与 ABF **共存**，形成三明治结构：

```
  ┌──────────────────┐
  │   ABF 增层（顶）  │  ← 芯片贴装面，布线层
  ├──────────────────┤
  │   玻璃核心载板    │  ← 机械支撑 + TGV 垂直互连
  ├──────────────────┤
  │   ABF 增层（底）  │  ← 基板连接面，布线层
  └──────────────────┘
```

这一架构被称为 **ABF-GCP（ABF Glass Core Package）**。ABF 提供成熟的精细布线能力（8-12μm L/S），玻璃提供刚性支撑和 CTE 匹配，二者互补而非替代。

### ❌ 误解三：芯片直接贴在玻璃上

**错误认知：** 芯片直接贴装在玻璃核心载板表面，玻璃需要承担芯片的精细 I/O 扇出。

**⭕ 正确理解：** 芯片贴装在 **ABF 增层表面**，而非玻璃表面。完整的贴装路径为：

1. 芯片 → micro-bump → ABF 增层（顶部）
2. ABF 增层布线 → TGV（穿过玻璃核心）
3. TGV → ABF 增层（底部）→ 封装基板 → BGA

这意味着芯片的 I/O 间距只需要与 ABF 增层的布线能力匹配（8-12μm L/S），而非与玻璃核心直接匹配。玻璃核心表面不需要承担精细光刻——精细光刻在 ABF 层完成。

### 9.4 NVIDIA Feynman 作为 Lead Product

CoPoS 的 9.5x reticle 目标不是凭空制定的——它直接对应 NVIDIA Feynman 架构的物理需求。

**Feynman 关键规格（GTC 2026 公布）：**

| 参数 | Feynman |
|------|---------|
| 制程节点 | TSMC A16（1.6nm）配合 Super Power Rail 背面供电 |
| 3D 堆叠 | 真正逻辑-on-逻辑 SoIC 混合键合 |
| GPU 算力 | >50 PFLOPS（单 GPU） |
| AI 推理性能 | ~5x Blackwell |
| 内存 | 定制 HBM（cHBM）— 12 堆叠 |
| LPU | Groq LP40（第三代），实时推理 |
| CPU | Rosa（NVIDIA 自研） |
| 互联 | NVLink 8（最多 1152 GPU 配置） |
| 封装功耗 | >2000W（预估） |
| 主封装方案 | TSMC CoPoS（玻璃核心 + ABF） |
| 备用方案 | Intel EMIB-T（据称在评估中） |

**为什么 Feynman 必须用 CoPoS？**
- Feynman GPU 逻辑芯片通过 SoIC 垂直堆叠，形成复合 die 面
- 12 个 HBM4 堆叠（每个 ~12×14mm）需要约 2000mm² 基板面积
- LP40 LPU 芯片 + Rosa CPU 芯片进一步增加面积需求
- 逻辑与存储总面积约 4000-6000mm²，加路由和外围 I/O 约需 **7000-8000mm²**
- CoWoS 5.5x reticle（~4720mm²）**过小**
- CoPoS 9.5x reticle（~7890mm²）是 **最小可行尺寸**

**热管理逻辑：**
虽然玻璃核心热导率（1-2 W/m·K）远低于硅（148 W/m·K），但主散热路径为纵向（芯片→散热器），非横向穿过玻璃。2000W+ 的封装功耗依赖：
- 芯片直接液冷冷板
- 堆叠逻辑 die 内的硅通孔热通道
- 高导热 TIM（热界面材料）
- SoIC 暴露硅背面实现背面散热

**客户锁定模式：**
NVIDIA 历来是台积电新封装节点的首发客户：
- **CoWoS-S** → H100/B200 首发
- **CoWoS-L** → Blackwell 首发
- **CoPoS** → Feynman 预计首发

这一模式反映了 NVIDIA 对早期良率波动的更高容忍度（全系统栈可控），以及对最大可用封装面积的刚性需求。

## 十一、总结：CoPoS 的技术定位

CoPoS 代表的是先进封装从"晶圆时代"向"面板时代"的范式转移，而非对 CoWoS 的局部优化。玻璃核心载板 + ABF 增层的三明治结构在材料科学和工艺工程两个维度同时实现突破：

**材料层面：** 玻璃解决了有机基板在超大封装下的 CTE 失配和翘曲问题，同时通过本征绝缘特性降低了高频信号损耗，并通过 TGV 实现了远超 TSV 的深宽比。

**工艺层面：** 面板级封装将面积利用率从 ~65% 提升至 >95%，使得数百亿美元的显示面板制造基础设施可以服务于半导体封装——这一资产复用逻辑本身就具有颠覆性。

**市场层面：** NVIDIA Feynman 的物理需求定义了 CoPoS 的 9.5x reticle 目标，而 AMD、Broadcom 等客户的跟进将进一步加速生态成熟。

CoPoS 并非一项孤立技术，而是台积电从 CoWoS → CoPoS → SoW-X 多代际封装路线图中的关键一环。其竞争力窗口预计覆盖至 2032 年。

## 一、FOPLP 基础

### 1.1 什么是 FOPLP

FOPLP（Fan-Out Panel Level Packaging）是一种以大面积矩形面板替代圆形晶圆作为载体的扇出型封装技术。芯片嵌入环氧模塑化合物（EMC），再分布层（RDL）将 I/O 触点从芯片边界向外延伸。

三个关键概念的分层关系：

- **Fan-in（扇入）：** RDL 走线和焊盘落在芯片面积之内
- **Fan-out（扇出）：** RDL 走线向外延伸，支持更多 I/O 和更大的焊球间距
- **Panel Level（面板级）：** 载体从圆形晶圆换成矩形面板（金属、玻璃或高分子材料）

### 1.2 FOPLP vs. FOWLP 对比

| 对比维度 | FOWLP（晶圆级） | FOPLP（面板级） |
|---|---|---|
| **载体形状** | 圆形晶圆（200mm / 300mm） | 矩形 / 方形面板（300–700mm） |
| **面积利用率** | ~85%（晶圆边缘浪费） | ~95%+（矩形贴合芯片排列） |
| **基础设施** | 晶圆厂设备 | PCB / 面板制造设备 |
| **光刻方式** | 晶圆步进式扫描（精细 2μm+） | 激光直写成像或面板步进式（较粗） |
| **介质材料** | 液态旋涂（PI、PBO、BCB） | 干膜层压或液态狭缝涂布 |
| **芯片尺寸上限** | ~12×12mm（翘曲约束） | 可支持更大尺寸 |
| **成本优势** | 基准线 | 大封装低 20–40% |
| **成熟度** | 成熟，大规模量产 | 新兴，研发至早期量产 |
| **最佳适用场景** | 中小封装、高 I/O 需求 | 大封装、成本驱动的高产量场景 |

### 1.3 关键优势

1. **成本降低 20–30%：** 一片 600×600mm 面板面积约为 300mm 晶圆的 5 倍——更高吞吐量、更好材料利用率，且可复用低成本 PCB 制造设备
2. **支持大芯片（>12×12mm）：** 晶圆级因翘曲难以处理的大芯片可在面板级实现
3. **矩形封装无边缘浪费：** 方形面板上排列矩形封装，裁切损耗远低于圆形晶圆
4. **单位产出的吞吐量更高：** 单次流程产出芯片数倍于晶圆级

### 1.4 关键劣势

1. **翘曲（warpage）：** 大面板上因 CTE 不匹配和应力梯度导致的面板弯曲是最核心的工程难题
2. **芯片偏移（die shift）：** 模塑流动和固化过程中芯片位置偏移，面板边缘比中心更严重
3. **RDL 分辨率受限：** PCB 级激光直写光刻难以匹配晶圆步进机的精细线宽
4. **材料兼容性：** 需要低温固化且能与模塑化合物共存的介质材料
5. **面板尺寸无统一标准：** 行业存在多种竞争尺寸，设备投入分散
6. **初始投资高：** 单条产线投资超 1–2 亿美元，需要高利用率才能回收

## 二、三种工艺流程

FOPLP 主要有三种工艺架构，按 RDL 与芯片贴装的时间顺序划分。

### 2.1 Chip-First Face-Down（芯片先置、面朝下）

这是最常规的流程：

1. 将已知合格芯片（KGD）面朝下贴装到临时载体面板上
2. 压缩模塑覆盖环氧模塑化合物
3. 移除临时载体（激光解键或机械释放）
4. 研磨模塑化合物至露出芯片背面或减薄封装厚度
5. 在芯片表面逐层构建 RDL（介质层 + Cu 金属化）
6. 植球（BGA）
7. 切割成单个封装

| 优势 | 劣势 |
|---|---|
| 流程简单、认知度高 | 芯片偏移在 RDL 制程前即已定型，无法修正 |
| 适合低成本的 PMIC、RF 芯片 | 精细间距需自适应 / 步进式光刻补偿偏移 |
| 面板级已有较成熟的产线 | 模塑后构建 RDL 需承受翘曲应力 |

### 2.2 Chip-First Face-Up（芯片先置、面朝上）

由三星 ePLP 和台积电 InFO 类工艺采用：

1. 在晶圆级芯片焊盘上电镀铜柱 / UBM
2. 芯片面朝上贴装到覆有热剥离胶带的载体面板
3. 压缩模塑
4. 背磨模塑化合物，露出铜柱顶部
5. 从露出的触点构建 RDL
6. 植球与切割

| 优势 | 劣势 |
|---|---|
| 研磨后露出的触点均为已知良好 | 芯片侧需预先制作铜柱，增加工序 |
| 无需临时键合 / 解键合步骤 | |
| 载体管理更简单 | |

### 2.3 RDL-First / Chip-Last（先做 RDL 再贴芯片）

被天马、三星 R&D 等采用：

1. 在覆有牺牲释放层的载体上先完成 RDL
2. 将芯片面朝下贴装到已完成的 RDL 上
3. 模塑覆盖
4. 激光解键合移除载体
5. 植球与切割

| 优势 | 劣势 |
|---|---|
| 在平整载体上制作 RDL，分辨率最高 | 需要已知良好 RDL 基板——电测困难 |
| RDL 不受模塑翘曲影响 | 模塑阶段芯片移位仍为问题 |
| 面板 / 显示厂商熟悉此路线（类似 TFT） | |

**三星 ECTC 2018 研究结论：** RDL-first 在玻璃面板上可实现 2/2 μm L/S，原因是"平坦载体上容易制作精细特征"。但面临约 20 万颗直径 20–25μm 焊点的电测挑战。

### 2.4 三种工艺横向对比

| 维度 | Chip-First Face-Down | Chip-First Face-Up | RDL-First |
|---|---|---|---|
| **贴装精度要求** | 高（芯片偏移不可修正） | 高（芯片偏移不可修正） | 中等（RDL 先行完成） |
| **RDL 良率影响** | 受模塑翘曲影响 | 受模塑翘曲影响 | 最优（在平整面制作） |
| **翘曲控制** | 中等 | 中等 | 最优（RDL 不受模塑应力） |
| **适用产品** | PMIC、RF、音频 IC | 移动 AP、可穿戴 SiP | 高密度 I/O、AI/HPC |
| **设备门槛** | 低 | 中 | 高（需面板级步进光刻） |
| **产业代表** | Innolux、Powertech | Samsung ePLP、TSMC InFO | 天马、Samsung R&D |

## 三、面板尺寸的碎片化

### 3.1 主要面板尺寸竞争格局

FOPLP 行业尚未收敛至统一标准，多种尺寸并行竞争：

| 面板尺寸 | 面积对比 300mm 晶圆 | 主要采用者 | 状态 |
|---|---|---|---|
| **300×300mm** | ~1.3× | TSMC（初期）、ASE | 试产 / 量产 |
| **415×510mm** | ~2.5× | 三星 R&D（从 600×600mm 转向至此） | 研发 |
| **500×400mm** | ~2.8× | 三星 SEMCO（ePLP 量产） | 规模量产 |
| **510×515mm** | ~3.0× | 力成（PTI）、SPIL | 规模量产 |
| **600×600mm** | ~5.0× | ASE（规划中）、三星（原方案）、Intel | 试产 / 研发 |
| **620×750mm** | ~6.0× | 群创（改造 Gen 3.5 LCD 产线） | 早期量产 |
| **650×650mm** | ~6.5× | Amkor（HPLT 研究） | 研发 |
| **700×700mm** | ~7.5× | Manz AG（演示） | 演示 |

### 3.2 大尺寸 vs. 小尺寸路线之争

**小面板路线（300–310mm）：**

- 翘曲风险低，设备可用性好
- 可改造晶圆厂现有工具
- 单线资本支出更低
- 但成本降低速度较慢

**大面板路线（510–600mm+）：**

- 面积利用率最高，成本降低潜力最大
- 翘曲和芯片偏移挑战最为严峻
- 需要定制化设备
- 单线投资高，对产能利用率要求苛刻

台积电选择 310×310mm 作为"训练场"再逐步升级；三星最初规划 600×600mm 后转向 415×510mm 以改善翘曲控制。

### 3.3 面板尺寸与成本模型（IMAPS 2024）

| 指标 | 300mm 晶圆 | 510×515mm 面板 | 600×600mm 面板 |
|---|---|---|---|
| 相对封装数量 / 次 | 1.0× | 3.0× | 5.0× |
| 成本节约（vs. 晶圆） | 基准线 | ~42% | ~50% |
| 良率盈亏平衡点 | 99% | ~95% | ~94% |
| RDL 成本增幅（vs. 基准线） | 基准线 | +79% | +119% |

**关键洞察：** 成本降低不随面积等比线性。RDL 环节获益最大，焊球贴装和芯片贴装收益有限。对昂贵芯片（晶圆成本 >1 万美元），1–2% 的良率损失即可抵消成本优势。

## 四、三星的 FOPLP / ePLP 路线

### 4.1 ePLP 技术概述

三星电机（SEMCO）开发了 ePLP（Embedded Panel Level Packaging），业界首款商业化 FOPLP 平台。技术特点是将芯片嵌入有机层压基板中，使用 PCB 芯板加激光切割腔体。

**关键规格：**

- 面板尺寸：500×400mm（量产），415×510mm（研发）
- RDL 层数：Exynos 9110 为 4 层
- RDL L/S：量产 10/10μm；Galaxy Watch 达 7/8μm；研发已实现 2/2μm
- 载体：有机（0.6mm，CTE 8ppm/℃）或玻璃（1.1mm，CTE 8ppm/℃）
- 通孔尺寸：6μm（2 层互联）
- 溅射设备：Evatec CLUSTERLINE 600（面板级，支持 650mm）

### 4.2 商业化产品演进

| 产品 | 年份 | 制程节点 | 封装形式 | 搭载设备 |
|---|---|---|---|---|
| Exynos 9110 | 2018 | 10nm | ePLP SiP-PoP（APE+PMIC+DRAM） | Galaxy Watch |
| Exynos W920 | 2021 | 5nm | FOPLP SiP-PoP | Galaxy Watch4 / 5 |
| Exynos W930 | 2023 | 5nm | FOPLP SiP-PoP | Galaxy Watch6 |
| Exynos W1000 | 2024 | 3nm GAA | FOPLP SiP-PoP（内置 PMIC） | Galaxy Watch7 / Ultra |
| Google Tensor G4 | 2024 | 4nm | FOPLP（部分） | Pixel 9 系列 |

### 4.3 技术路线图（2025–2027）

| 阶段 | 时间节点 | 说明 |
|---|---|---|
| 塑料基板 FOPLP（PMIC、移动 AP） | 已量产 | 当前商业化基线 |
| 玻璃基板原型 | 目标 2025 | 三星电机试产线 |
| 面板尺寸调整 | 2026 年 3 月 | 从 600×600mm 转向 415×510mm，改善翘曲控制 |
| 玻璃基板规模化量产 | 目标 2026–2027 | 与 Intel 玻璃基板进度竞争 |
| 三星电子直接投资评估 | 进行中 | 三星电子可能直接注资（独立于所持 23.7% SEMCO 股份） |

### 4.4 竞争定位

| 优势 | 说明 |
|---|---|
| **先发优势** | 2018 年 Exynos 9110 率先商用 FOPLP，早于台积电 InFO |
| **3nm GAA + FOPLP 整合** | Exynos W1000 验证了最先进制程与面板级封装的结合 |
| **玻璃基板研发领先** | ECTC 2018 已展示 2/2μm L/S 玻璃面板结果 |
| **垂直整合** | 可调用三星显示器和元器件部门的技术资源 |

| 劣势 | 说明 |
|---|---|
| **客户集中** | 主要服务三星自研产品 |
| **产能规模** | 远不及台积电 CoWoS / InFO |
| **可穿戴聚焦** | ePLP 针对小型封装优化，不适配超大 AI 芯片 |
| **玻璃基板良率** | 仍处原型阶段，规模量产待验证 |

## 五、ASE / SPIL 的 VIPack 平台

### 5.1 概述

ASE 是全球最大的 OSAT（市占率 35%+），2016 年与 SPIL 合并后以控股公司运行，两家实体保持法律独立。ASE / SPIL 在 FOPLP 领域实行双尺寸并行策略。

### 5.2 FOPLP 投资时间线

| 时间 | 里程碑 |
|---|---|
| 2024 年 10 月 | SPIL 子公司公告约 NT$80 亿（~$2.5 亿）先进封装设备采购 |
| 2025 年 1 月 | SPIL 在台中潭子科学园启用新先进封装厂 |
| 2025 年 Q2 | 面板级封装设备安装到位 |
| 2025–2026 | 三座新厂扩建产能 |
| 2025 年（目标） | 300×300mm 产线投产；600×600mm 试产 |

### 5.3 VIPack 平台核心技术

| 技术 | 全称 | 说明 |
|---|---|---|
| **FOPoP** | Fan-Out Package-on-Package | 高密度 RDL 封装，用于存储-逻辑垂直堆叠 |
| **FOCoS** | Fan-Out Chip-on-Substrate | 高性价比扇出 RDL 芯粒集成（2/2μm 至 10/10μm L/S） |
| **FOCoS-Bridge** | FOCoS with Embedded Bridge | 内嵌硅桥实现逻辑与存储间高密度互联 |
| **FOSiP** | Fan-Out System-in-Package | 系统级集成，含 RF / 模拟 / 无源器件 |
| **2.5D / 3D IC** | — | 基于 TSV 的高性能异质集成 |

### 5.4 FOCoS-Bridge 突破（2023）

ASE 完成了一款 70×78mm 大型封装的认证，包含：
- 2 颗 ASIC
- 8 颗 HBM
- 通过 8 个嵌入式硅桥互联
- 封装面积接近 2 倍光罩极限

### 5.5 双尺寸并行策略

ASE 同时推进两条面板路线：
- **310×310mm：** 近期量产目标，利用 PCB 级设备
- **600×600mm：** 长期大规模降本目标，公司指出 310mm 产线在大中介层（>3× reticle）场景下效率已达晶圆的 1.78 倍

### 5.6 竞争定位

- **最大 OSAT 优势：** 客户基础广泛，可充当台积电 AI 芯片的"第二供应商"
- **芯粒聚焦：** FOCoS-Bridge 直接对标 CoWoS-L 的 AI / HPC 芯粒集成
- **投资决心：** ~$2.5 亿以上的重资本承诺

## 六、Amkor 的面板级封装

### 6.1 HPLT（Hybrid Panel-Level Technology）

Amkor 正在开发的混合面板级技术，将面板级 RDL 加工与子面板级芯片贴装相结合。

**面板规格（来源：Amkor 葡萄牙研发总监 Eoin O'Toole）：**

| 参数 | 规格 |
|---|---|
| 面板尺寸 | 650×650mm 玻璃 |
| 等效产能 | 4 片 300mm 晶圆 / 9 片 200mm 晶圆 / 16 片 150mm 晶圆 |
| 支持封装类型 | WLCSP、WLFO（Chip-First）、RDL-First、SiP |
| RDL 层数 | 已验证 6 层测试载体 |
| 工艺顺序 | 子面板 / 晶圆临时键合到玻璃 → 构建 RDL → 倒装贴片 |
| 模塑方式 | MUF 或 CUF + 包封模塑 |
| 解键合 | 激光解键合（当前局限——需先切割面板） |

### 6.2 HPLT 工艺步骤

1. 将基板（晶圆或子面板）用黏合剂临时键合到大玻璃面板
2. 在玻璃上逐层构建 RDL：从顶层 UBM 向下到最底层
3. 每层 RDL 间施加介质层
4. 最终 UBM 层用于倒装芯片贴装
5. 倒装贴片后 MUF 或 CUF + 模塑
6. 解键合剥离玻璃面板

### 6.3 成本策略

HPLT 将降本重心放在最昂贵的环节——RDL 本身。涂布、显影、曝光、固化、PVD、电镀、剥离、蚀刻等步骤均可在大面板上并行处理，实现规模经济。

### 6.4 市场定位

| 维度 | 说明 |
|---|---|
| **面板尺寸** | 650×650mm（OSAT 中最大研究尺寸） |
| **资本支出** | "单线初始投资可超 1–2 亿美元"——Amkor SVP Doug Scott |
| **目标市场** | 从成本敏感型（消费 / IoT / 汽车 PMIC）向 AI / HPC / 5G 拓展 |
| **可靠性验证** | 6 层 RDL Chip-Last 测试载体应力测试后"未发现失效" |
| **主要竞争对手** | ASE、三星 SEMCO、台积电、力成（PTI）、NEPES |
| **关键制约** | 面板级资本支出高，需填满产能 |

### 6.5 时间线

- **2024：** HPLT 研究发表，先进节点 FOPLP 仍处早期
- **2025–2026：** IDC 预计 Amkor 参与先进封装供应链，承接 CoWoS 溢出需求
- **2026–2027：** TrendForce 预测 FOPLP 在先进节点加速采用
- **STMicro（法国）：** 700×700mm PLP 试产线预计 2026 年建成

## 七、JCET 的 XDFOI 平台

### 7.1 概述

JCET 集团（江苏长电科技）是中国最大的 OSAT，全球排名前五。通过旗下子公司（尤其是江阴芯智联 SJ Semiconductor）积极布局扇出型封装。

### 7.2 核心技术平台

| 平台 | 说明 |
|---|---|
| **eWLCSP** | 包封晶圆级芯片尺寸封装——利用重构和晶圆级模塑，不依赖来料晶圆直径 |
| **eWLB** | 嵌入式晶圆级 BGA——已验证 12×12mm 封装批量量产 |
| **XDFOI** | 高密度多维扇出芯粒方案，覆盖 2D、2.5D、3D 集成——已稳定量产 |
| **FlexLine** | 灵活的制造方案，不依赖来料晶圆尺寸实现低成本面板级加工 |

### 7.3 关键专利

| 专利 | 内容概要 |
|---|---|
| 扇出型系统级封装（US 2024/0088000 A1）——芯智联 2023 | 集成多种功能芯片、桥接高密度 I/O、散热盖；支持处理器 + 存储 + 光电子 + MEMS 单封装 |
| 双层面布线扇出（US 2024/0047326 A1）——芯智联 | 降低最小线宽、提高线密度；基板单元与次级扇出单元分开制备缩短周期 |
| 翘曲控制 + 散热（US 12,148,681）——JCET 2024 | 在 RDL 中嵌入假晶圆抑制翘曲并形成连续散热通道 |
| 3D 互联扇出（CN106876363A）——JCET | 金属柱纵向互连 + 引线键合 + 塑封 |

### 7.4 汽车级与 HPC

- 车规级扇出：1 / 2 / 3 层 RDL，L/S 8μm 已进入量产
- HPC：提供从计算到存储、电源、互联的一站式方案
- JCET 的 FOPLP 主要走晶圆衍生路线（通过 FlexLine 概念），而非专用大面板产线

### 8.3 面板厂商的跨界优势

- **资产再利用：** 闲置 LCD 产线（Gen 3.5–4.5）已充分折旧，改造成本极低
- **大基板经验：** 数十年处理大型玻璃面板的工艺能力

### 8.4 跨界挑战

- **工艺迁移：** 需要铜电镀（vs. TFT 的溅射）以及干 / 湿法蚀刻的化学体系调整
- **洁净度：** 半导体级洁净度远超显示面板要求
- **精细 RDL：** 显示行业分辨率通常 >5μm，半导体需求 2–10μm
- **客户认证：** 新进入者需经历漫长的认证周期

## 十、FOPLP vs. TSMC CoPoS

### 10.1 架构对比

| 维度 | FOPLP（通用） | TSMC CoPoS |
|---|---|---|
| **全称** | Fan-Out Panel Level Packaging | Chip-on-Panel-on-Substrate |
| **中介层** | 无（RDL 直接在模塑化合物上） | 玻璃芯板 + ABF 增层（GCP 结构） |
| **I/O 密度** | 较低（LDI 光刻限制） | 较高（精细 RDL + 硅桥） |
| **信号完整性** | 中等 | 优越（中介层布线） |
| **目标市场** | 中端（PMIC、RF、IoT、手机、汽车） | 高端（AI GPU + HBM、HPC） |
| **主要成本驱动** | 面板利用率 | RDL + 玻璃芯板加工 |
| **初始面板尺寸** | 300–600mm+ | 310×310mm（向 515×510mm 扩展） |
| **大规模量产时间** | 2018（三星）、2025（群创） | 目标 2028 下半年 |
| **适用芯片** | 单芯片或简单 SiP | 多芯粒 + 多 HBM 堆叠 |

### 10.2 概念定位

FOPLP 的本质是"面板化的 FOWLP"——将晶圆级扇出封装的成本优化逻辑搬到面板上，面向广泛的中低端应用。CoPoS 则是"面板化的 CoWoS"——保留 CoWoS 中介层概念（玻璃芯板 + ABF），但将载体从圆晶圆换成方面板，只瞄准超大 AI 芯片。

两者将长期共存，服务于不同的性能-成本层级。

### 10.3 应用场景选择

| 应用场景 | 推荐方案 | 理由 |
|---|---|---|
| 智能手机 PMIC | FOPLP | 成本驱动，I/O 需求适中 |
| 可穿戴 AP + PMIC | FOPLP | 三星 ePLP 已验证，外形优越 |
| 车载雷达 | FOPLP | 成熟的 Chip-First 方案已获车规认证 |
| GPU + HBM3 / HBM4 | CoPoS | 需要精细间距互联和信号完整性 |
| 大型 AI 加速器 | CoPoS | >70×70mm，多芯粒 + HBM 堆叠 |
| 中端 ASIC | FOPLP | SiP 集成性价比更优 |
| RF 前端模块 | FOPLP | 面板级 RDL 的 RF 性能已够用 |

## 十一、总结与展望

FOPLP 正处于从研发走向规模量产的关键转折期。三星 ePLP 已率先在可穿戴市场验证了面板级封装的商业可行性，群创利用闲置 LCD 产线改造的路径为面板厂商树立了样板，ASE 和 Amkor 等 OSAT 巨头正在加码投入。

行业面临的三大结构性挑战仍然有待解决：面板尺寸标准无法收敛导致设备和材料投入分散、翘曲和芯片偏移在超大面板上的工程瓶颈、以及面板级良率在昂贵芯片场景下的经济性敏感度。按 Yole Group 预测，面板级封装市场将从 2024 年的约 1.6 亿美元增长至 2030 年的约 6.5–6.7 亿美元（CAGR ~27%），在整个先进封装 ~800 亿美元市场中占比仍不足 1%，但其战略价值在于为大型封装提供了晶圆级所不具备的成本扩展路径。

展望 2027–2028 年，随着 CoWoS 产能瓶颈持续传导，AI 芯片封装需求将推动面板级封装迎来关键拐点。届时 FOPLP 的中低端应用和 CoPoS 的高端应用将形成互补分工，共同承接从晶圆级封装溢出的产能需求。

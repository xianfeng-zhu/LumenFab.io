## 0. IC 基板：裸片与 PCB 之间的关键互连层

<TermNote label="IC 基板" note="IC substrate，也称封装基板或 IC 载板。位于裸片与 PCB 之间的精密互连层，承担供电、高速信号扇出和机械支撑，占先进封装总成本约 30–40%" /> 是半导体封装中最精密的物理承载结构。它的核心角色是将裸片侧细间距 I/O（40–150 μm）扇出到 PCB 侧可焊接的 BGA 球距（0.3–1.0 mm），同时提供供电分配、高速信号传输和机械支撑。

IC 基板的制造精度远高于标准 PCB。典型 PCB 的线宽/线距（L/S）在 50 μm 以上，而 IC 基板主流量产节点为 **20/20 μm**，先进节点低至 **5/5 μm**。基板层数从低端封装的 2–4 层到高端 AI 芯片封装的 18–22 层不等，每层之间的对位精度要求优于 35 μm。

基板成本在封装总成本中的占比随封装复杂度上升。FC-BGA 封装中基板约占 30–40%；在 CoWoS、2.5D 集成等高端场景中，基板的材料与工艺复杂度进一步提升，成本占比可超过 40%。

## 1. Core 与 Coreless 基板架构

IC 基板按结构可分为核心基板（core-based）和无核心基板（coreless）两大类。两者的本质区别在于是否保留一块刚性芯板作为制造基底。

### 1.1 Core 基板

核心基板以一块刚性芯板为机械基础，芯板材料通常为 <TermNote label="BT 树脂" note="Bismaleimide-Triazine，双马-三嗪树脂。由三菱瓦斯化学（MGC）于 1977 年商业化的热固性树脂，以玻璃纤维布增强，广泛用于 IC 基板核心层和内存封装基板" /> 加玻璃纤维布、两面覆铜箔。芯板两侧再通过积层工艺添加 ABF 或 BT 预浸料积层。

**常见积层结构：** 1+2+1、2+2+2、4+4+4、6+4+6、8+8+8，其中第一个数字代表顶层积层数、第二个为核心层数、第三个为底层积层数。

| 参数 | 典型值 |
|------|--------|
| 芯板厚度 | 0.06–0.8 mm |
| 总厚度 | 130–670 μm |
| 芯板钻孔 | 机械钻通孔（PTH） |
| 芯板线路 | 减成法（subtractive），密度受限 |
| 积层方式 | 上下两侧分别积层 |
| 通孔填充 | 需填孔+抛光，工艺步骤增加 |

**优点：** 工艺成熟，制造过程中机械稳定性好，低层数设计成本较低。
**缺点：** 芯板与积层区介电材料不同导致电学不连续；机械钻孔限制通孔密度；整体较厚；芯板通孔需填孔和抛光。

### 1.2 Coreless 基板

无核心基板没有永久刚性芯板。所有层在临时载板（陶瓷或金属）上依次积层制造，最后移除载板，得到全积层的均匀结构。

| 参数 | 典型值 |
|------|--------|
| 所有层介质 | 同一材料（通常 ABF） |
| 所有通孔 | 激光钻孔（无机械钻孔） |
| 线路制作 | 全层 SAP |
| 总厚度 | 115–410 μm |
| 载板 | 陶瓷或金属（最后移除） |

**优点：**
- **更薄**（115–410 μm vs. core 的 130–670 μm）
- **电学性能更好**——单一介电材料，信号路径短
- **密度更高**——全层可使用 SAP 细线工艺
- 无芯板通孔密度限制

**缺点：**
- 工序时间更长（逐层单侧积层）
- 翘曲控制是关键难点（无芯板刚性支撑）
- 层间对位精度要求高（< 35 μm）
- 工艺复杂度更高

**翘曲数据（Unimicron / IMPACT 2010）：** Coreless 6+1 ABF 结构与常规 2+2+2（0.4 mm 芯板）的翘曲量均在 ~100 μm 水平，均满足量产规格。

### 1.3 选型考量

| 场景 | 推荐架构 | 原因 |
|------|----------|------|
| 内存（NAND/DRAM） | Core | 层数少，BT 成本低，工艺成熟 |
| 中低端 FC-BGA | Core | 翘曲控制好，良率高 |
| 高端 CPU/GPU/AI 加速器 | Coreless | 高密度、薄型、电学性能优异 |
| 多芯片集成（2.5D/3D） | Coreless | 全层 SAP 支持更细布线 |

## 2. 介电材料：BT 树脂与 ABF 薄膜

IC 基板的介电材料决定了它的线宽能力、电学性能和成本。基板市场目前主要使用两种材料：BT 树脂和 <TermNote label="ABF 薄膜" note="Ajinomoto Build-up Film，味之素积层薄膜。日本味之素公司开发的环氧树脂基介电薄膜，无玻璃纤维增强，是先进封装基板的核心积层材料，自 1999 年推出以来逐步成为 FC-BGA 基板的行业标准介电材料" />。

### 2.1 BT 树脂

| 参数 | 数值 |
|------|------|
| 开发商 | 三菱瓦斯化学（MGC），1977 年商业化 |
| 成分 | BMI + 三嗪（氰酸酯）+ 改性剂（环氧、PPE）+ 玻璃纤维布 |
| Tg | 180–330°C |
| CTE（X-Y 方向） | 10–15 ppm/°C（改性后可达 8.8–9.0 ppm/°C） |
| Dk | ~3.5–4.5 |
| Df | 0.005–0.015 |
| 吸水率 | < 0.1% |
| 最小 L/S | ≥ 12–15 μm |
| 实用层数 | 2–4 层（可更多但难度大） |
| 激光钻孔 | 因玻璃纤维存在较困难 |
| 单价 | ~JPY 3,000–5,000 / m² |
| 应用 | NAND、DRAM、RF 芯片、MEMS、LED、引线键合 BGA |

**制造流程：**
1. BT 树脂溶解为清漆（A-stage）
2. 浸渍玻璃纤维布
3. 干燥切割为预浸料（B-stage）
4. 在热压条件下与铜箔层压成型为覆铜板（CCL）

**热处理细节：** BT 基板在低 Tg（~187°C，约 90% 聚合度）下加工，随后在 190–200°C 热处理 1–3 小时，将 Tg 提升至 215°C 以上（>95% 聚合度），防止后续积层时的翘曲。

### 2.2 ABF 薄膜

| 参数 | 数值 |
|------|------|
| 开发商 | 味之素（日本），1999 年推出 |
| 成分 | 环氧树脂 + 固化剂 + 二氧化硅填料（球状，0.1–0.5 μm）+ 助剂 |
| 增强材料 | 无玻璃纤维布（可制作更细线路） |
| Dk | ~3.2–3.4（10 GHz） |
| Df | ~0.010–0.015（10 GHz） |
| 最小 L/S | ≥ 5–6 μm（SAP 工艺） |
| 层数 | 6–22 层（已验证可至 50 层） |
| 激光钻孔 | 容易，微通孔 15–25 μm |
| 单价 | ~JPY 38,000–52,000 / m²（10–16 层） |
| 膜厚（压合后） | 30–70 μm |
| 应用 | 高端 CPU、GPU、AI 加速器、服务器、网络处理器（FC-BGA） |

### 2.3 对比总结

| 参数 | BT 树脂 | ABF 薄膜 |
|------|---------|----------|
| 玻璃纤维增强 | 有 | 无 |
| 最小 L/S | 12–15 μm | 5–6 μm |
| 最大层数 | ~8（实用） | 22+（可至 50） |
| Dk | 3.5–4.5 | 3.2–3.4 |
| Df | 0.005–0.015 | 0.010–0.015 |
| 激光通孔尺寸 | 50+ μm | 15–25 μm |
| 单价 | ~JPY 3k–5k / m² | ~JPY 38k–52k / m² |
| 主要应用 | 内存、RF、MEMS | CPU、GPU、AI、网络 |

## 3. ABF 薄膜详解

### 3.1 产品系列演进

味之素的 ABF 产品以固化剂类型划分系列，从 1999 年至今持续迭代：

| 系列 | 固化剂 | 关键特征 | 时间线 |
|------|--------|----------|--------|
| GX 系列 | 酚醛树脂 | 标准型 | 原始系列（1999） |
| — GX-13 | 酚醛 | 首款大规模采用 | ~2005 |
| — GX-92 | 酚醛 | 低粗糙度、低 CTE | ~2011 |
| — GX-T31 | 酚醛 | 最低 CTE，吸水率较 GX-13 降低约 50% | 后期 |
| GY 系列 | 酚酯 | 低介电 | 数据有限 |
| GZ 系列 | 氰酸酯 | 高 Tg、极低 Df | 当前主力 |
| — GZ-22 | 氰酸酯 | 高端 | 当前 |
| — GZ-41 | 氰酸酯 | 低 Df、高 Tg、高模量 | 当前 |
| GL 系列 | — | 二氧化硅含量 ~72 wt%，超低 CTE | 近期 |
| GT 系列 | — | 下一代 | 开发中 |

**代际性能趋势：**
- CTE：逐代降低（填料含量增加）
- Df：逐代降低（损耗下降）
- 模量：逐代提高
- 延伸率：逐代降低（薄膜更脆）
- Dk：轻微升高（填料占比增加导致）

**关键数据点：**
- GZ 系列（氰酸酯完全固化）：Df ~0.006，Dk ~2.6（1 GHz）
- GX 系列：二氧化硅含量 ~38 wt%
- GL 系列：二氧化硅含量 ~72 wt%
- 填料颗粒尺寸：从 0.5 μm 降至 0.1 μm
- 表面粗糙度：从 400 nm 降至 100 nm 以下

### 3.2 ABF 供应链：味之素的垄断地位

| 指标 | 数值 |
|------|------|
| 味之素精技（Ajinomoto Fine-Techno）全球份额 | >95% |
| 积水化学（Sekisui Chemical） | ~5%，正在开发竞争产品 |
| 中/台替代厂商（TBF、EBF、GBF） | 早期验证阶段，距量产尚远 |
| 全球 ABF 薄膜市场（2024） | ~USD 5.14 亿 |
| 预测（2032） | ~USD 10.69 亿（CAGR 10.93%） |
| 产地占比 | 日本 98.66% |
| 2026 供需缺口 | ~10% |
| 2028 供需缺口 | 42–46% |

**垄断成因：**
1. **110 年以上氨基酸化学积累**——ABF 核心化学源自味之素的氨基酸研发
2. **200 多项核心专利**——覆盖材料组成、生产设备、应用方法
3. **1–3 年认证周期**——客户切换供应商的成本极高
4. **良率差距**——味之素良率 95–98%，新进入者仅 75–85%
5. **垂直整合**——关键原材料自产

**开发中的竞争薄膜：**
- 积水化学（日本）——NX04H、NQ07XP，下一代 Df 可达 0.0023
- NBF（原诺菲，被洛特科创收购）——瞄准中端市场
- 国产薄膜——早期验证阶段，16 层以上 ABF、HBM 和高端 AI 芯片应用差距显著

## 4. 制造工艺：SAP 与 mSAP

### 4.1 SAP（半加成工艺）

<TermNote label="SAP" note="Semi-Additive Process，半加成工艺。在极薄化学铜种子层上构建电路的制造方法，通过电镀在光刻胶开口中形成线路后去除种子层，可实现最细的线宽/线距，是先进 IC 基板的核心工艺" /> 适用于 L/S ≤ 15 μm 的场景，是 FC-BGA、2.5D 中介层等高端基板的标准工艺。

**完整流程：**

| 步骤 | 描述 | 细节 |
|------|------|------|
| 1 | 内层准备 | 芯板完成铜线路（减成法） |
| 2 | ABF 压膜 | 真空压合 ABF 薄膜 ~110°C，180°C 固化 30 分钟 |
| 3 | 激光钻孔 | CO₂ 激光制作微通孔（25–50 μm），膨松+高锰酸钾去钻污 |
| 4 | 化学铜种子层 | 沉积 ~0.5–2 μm 化学铜（钯催化剂+化学还原） |
| 5 | 光刻胶图形 | 贴干膜或涂液体光刻胶，曝光显影 |
| 6 | 电镀加厚 | 在光刻胶开口内电镀铜，形成线路并填充通孔 |
| 7 | 去胶 | 去除光刻胶 |
| 8 | 闪蚀（flash etch） | 用选择性化学液去除线路间的薄种子层 |

**关键工艺细节：**
- **去钻污与 PCB 不同：** SAP 中整个 ABF 表面（不仅是通孔壁）都需要处理出微粗糙度，以保证种子层附着力
- **化学铜厚度：** ~1–2 μm（标准 PCB 的 2 倍），沉积速率低 50% 以上，化学品为 CP 级（成本 3 倍）
- **一块 18×24 英寸基板：** 盲孔数量可超 80 万个
- **电镀：** 高速酸性铜浴，钛不溶性阳极，阴阳极距从 20 cm 缩至 5–10 cm（立式）或 2 cm（卧式），浴温从 20°C 升至 40°C
- **浴液维护：** 因不溶性阳极导致 TOC 积聚，每周排放 1/10 浴液

**闪蚀化学（关键步骤）：**

1–2 μm 的薄种子层必须在不侵蚀厚电镀线路（~10–20 μm）的前提下完全去除。典型蚀刻液配方：

- H₂O₂（氧化剂）+ H₂SO₄（酸性介质）
- 四唑类化合物（对电镀铜的选择性抑制剂）
- 氯离子（电位调节剂）
- 目标选择性：化学铜与电镀铜的蚀刻速率比 ≥ 2.1

**L/S 能力：** 量产 < 10/10 μm，先进 / 实验室可达 5/5 μm 及以下。

### 4.2 mSAP（改良半加成工艺）

<TermNote label="mSAP" note="Modified Semi-Additive Process，改良半加成工艺。以超薄铜箔（2–5 μm）代替化学铜作为起始层，结合加法和减法的混合工艺，适用于 L/S 20–30 μm 的中密度基板制造" /> 使用超薄铜箔（2–5 μm）代替化学铜种子层，是加法和减法工艺的混合方案。

**SAP 与 mSAP 对比：**

| 参数 | SAP | mSAP |
|------|-----|------|
| 起始层 | 化学铜（~0.5–1 μm） | 超薄铜箔（2–5 μm，附于载板上） |
| 种子层沉积 | 化学浴 | 预层压铜箔 |
| 材料成本 | 高（必须用 ABF） | 较低（可用标准 CCL+超薄铜箔） |
| 设备成本 | 极高（溅射、化学铜线） | 中等（适配现有产线） |
| 工艺复杂度 | 高（步骤多 ~30%） | 中等 |
| 量产 L/S | < 15/15 μm | 20–30 μm |
| 先进 L/S | 5/5 μm（实验室） | 15–20 μm |
| 截面形状 | 近乎完美矩形 | 良好，不如 SAP |
| 成本增幅 | 较传统工艺高 50–100%+ | 较传统工艺高 20–30% |
| 主要用途 | FC-BGA、高端 IC 基板 | SLP、服务器板、模块 |

### 4.3 SAP vs. mSAP 选型指南

| 应用场景 | 推荐工艺 |
|----------|----------|
| FC-BGA for CPU/GPU/AI | SAP（< 15 μm），mSAP（15–30 μm） |
| 智能手机 SLP | mSAP |
| AI 服务器 / 高速 PCB | mSAP |
| CoWoS / 2.5D/3D 封装 | SAP / aSAP |
| 800G / 1.6T 光模块 | mSAP + RCC |
| 医疗高密度基板 | SAP |

**aSAP（advanced SAP）：** 下一阶段演进，采用气相沉积种子层，目标 L/S 5–8 μm，面向 chiplets 和 2.5D/3D 场景。

### 6.4 各节点关键挑战

**10/10 μm（当前量产）：**
- 闪蚀的侧蚀控制
- 光刻胶在光滑 ABF 表面的附着力
- AOI 分辨率

**5/5 μm（2025）：**
- ABF 表面粗糙度须 ≤ 100 nm 以确保细线附着力
- 干膜光刻胶达到深宽比极限（~4:1），需改用液态光刻胶
- 缺陷控制：5 μm L/S 下，2 μm 的凸起即导致桥接
- 化学铜晶粒边界粗糙度影响显著

**2/2 μm（2026–2027）：**
- 介电层固化导致的有机基板尺寸变形
- 需要光敏介电层（PID）或硬掩模 + 干法刻蚀
- 闪蚀选择性不足，可能需要类大马士革工艺
- 通孔对位精度要求超过当前激光钻孔能力
- 板内均匀性至关重要

## 7. 玻璃核心基板——新兴技术

### 7.1 什么是玻璃核心基板

玻璃核心基板以玻璃面板替代有机层压核心，被广泛视为 IC 基板技术的下一个转折点。

**相比有机核心的潜在优势：**
- 尺寸稳定性优越（低 TTV、低翘曲）
- CTE 与硅接近（可 < 5 ppm/°C）
- 介电损耗更低
- 支持更细线路（sub-2 μm L/S）
- 信号路径更长、损耗更低
- 可实现 110 × 110 mm 及以上的封装尺寸

### 7.2 关键参与者和时间线

| 厂商 | 试产/样品 | 量产目标 | 备注 |
|------|----------|---------|------|
| Intel | 试产线 ~2025 | 2026–2030 | 2023 年 9 月率先公开；2025 年中重申路线 |
| SEMCO | 原型 2025 | 2026–2027 | 2024 年 3 月跨部门联盟；2025 年 8 月从 Intel 招聘负责人 |
| Absolics（SK 集团） | 已运行产线 | 2025 年底 | 美国佐治亚州 $3 亿工厂；与 AMD 合作 |
| AMD | 样品评估 | 2025–2026 | 多源采购策略 |
| AT&S | 研究阶段 | 待定 | IPCEI 资助研发，奥地利莱奥本 |

### 7.3 技术状态

- **TGV 工艺：** Intel 于 ECTC 2025 展示了 1:20 深宽比的玻璃通孔
- **SEMCO：** 800 μm 厚玻璃核心、8 层、80 × 80 mm（原型验证）；105 × 105 mm、840 μm 厚度正在验证，目标 2025 年完成
- **市场：** 初步量产预计 ~2026 年（~2,000 m² 出货量），2027 年增至 ~8,000 m²
- **首批应用：** AI 服务器 CPU/GPU、交换芯片、RF 模块、共封装光学

### 7.4 当前挑战

- 玻璃的脆性——不适合消费电子手机或汽车（物理冲击）
- 新建生产线资本投入高
- TGV 成型和缺陷检测仍有待优化
- Intel 在新领导层下的战略不确定性（可能外购而非自产）

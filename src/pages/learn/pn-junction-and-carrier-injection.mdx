## One-Sentence Answer

PN 结通过正向偏置把电子和空穴注入到结区或有源区，让它们复合；在合适材料和结构里，这种复合可以产生 LED 光或激光增益。

## Why This Exists

如果只说“直接带隙材料会发光”，仍然少了一步工程逻辑：器件必须把载流子送到正确位置，并让它们和光模式重叠。

## 费米能级：电子占据概率的基准面

在深入 PN 结之前，需要先理解一个概念：电子在能带中如何分布。

热平衡下，电子按**费米-狄拉克分布**占据能态：

```
f(E) = 1 / (1 + e^((E − E_F)/kT))
```

**费米能级 E_F** 是电子占据概率为 50% 的能量基准面。在 E_F 以下，能态大部分被电子填满；在 E_F 以上，能态大部分空着。E_F 离导带越近，导带里的电子越多；离价带越近，价带里的空穴越多。

热平衡时整个材料只有一个 E_F。但 PN 结被正向偏置后，情况改变：

- n 区被注入大量电子 → 导带电子浓度升高 → 从 n 区导带角度看，需要一个更高的"准费米能级" E_Fn 来描述
- p 区被注入大量空穴 → 价带空穴浓度升高 → 从 p 区价带角度看，需要一个更低的"准费米能级" E_Fp 来描述

于是在有源区，**费米能级被"劈开"**：导带用 E_Fn 描述电子分布，价带用 E_Fp 描述空穴分布。两者之间的距离，直接决定了材料是吸收光还是放大光。

## 粒子数反转：从吸收到增益的门槛

一个光子（hν = E_g）穿过材料时，同时面临两个竞争过程：吸收（光子被价带电子吃掉）和受激辐射（光子触发导带电子跳下来，多出一个光子）。两者微观截面完全相同。

谁赢谁输，只看各自阵营里有多少"能参与"的电子。用量子语言：

```
受激辐射速率 ∝ f_c × (1−f_v)   —— 导带有电子、价带有空穴
吸收速率     ∝ f_v × (1−f_c)   —— 价带有电子、导带有空位

净增益 ∝ f_c − f_v
```

f_c 是导带能态的电子占据概率，f_v 是价带对应能态的空穴占据概率。费米-狄拉克分布代入后，f_c > f_v 的条件化简为：

```
E_Fn − E_Fp > E_g
```

两个准费米能级的距离必须大于带隙——这就是**粒子数反转条件**。它等价于说：导带里的电子比同能量处价带的电子更多，光子经过时，触发受激辐射的概率大于被吸收的概率。

热平衡下这个条件永远不成立（E_Fn = E_Fp = E_F，E_F 在带隙中），所以普通材料在通信波段表现为吸收而非增益。必须通过**注入电流**（或泵浦光）强行提高 E_Fn、压低 E_Fp，才能劈开费米能级、建立反转。反转一旦建立，材料从"吸光"变为"放大光"——这就是激光器阈值条件的微观起源。

这个条件也直接解释了之前讨论的温度敏感性：温度升高 → 费米分布展宽（kT 变大）→ f_c 自动变小、f_v 自动变大 → 更难维持 f_c > f_v → 需要更大注入电流才能维持反转 → 阈值电流上升 → 这就是 T₀ 的底层原因。

## Physical Principle

n 型半导体以电子为主要载流子，p 型半导体以空穴为主要载流子。两者接触后，界面附近形成耗尽层和内建电场。

正向偏置会降低势垒，使电子和空穴更容易注入并复合。当注入足够强、满足 E_Fn − E_Fp > E_g 时，有源区建立粒子数反转，材料从吸收变为增益——这是激光器与 LED 在物理上的分界线（LED 只需要复合发光，不需要反转）。复合释放的能量可能：

- 变成光子，也就是辐射复合。
- 变成晶格振动或缺陷相关耗散，也就是非辐射复合。

## Engineering Implementation

普通 PN 结只能解释“电子和空穴怎么相遇”。通信激光器还需要更多结构：

- 异质结把载流子限制在薄的 active region。
- 波导把光限制在同一片区域附近。
- 金属接触和电流通道决定注入是否均匀。
- 外延质量和缺陷控制决定非辐射复合有多严重。

所以激光器不是“一个 PN 结加两根线”这么简单。PN 结是入口，异质结构、量子阱、波导、腔体和封装才把它变成可用器件。

## Key Metrics

- forward voltage。
- injection efficiency。
- carrier confinement。
- overlap between optical mode and active region。
- leakage current。
- defect-assisted recombination。

## Common Misconceptions

- p 型材料整体不等于带正电，n 型材料整体不等于带负电。
- PN 结可以发光，但高效激光器还需要增益、反馈和光学约束。
- “注入更多电流”不总是更好，过热和泄漏会破坏效率与寿命。

## Short Version

PN 结的作用是把电子和空穴带到一起。材料决定复合是否容易发光，异质结构决定载流子和光场是否被限制在正确位置。激光器在 PN 注入之上，还要加增益、反馈、约束和热管理。

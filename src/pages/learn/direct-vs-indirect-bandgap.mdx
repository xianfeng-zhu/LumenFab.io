## One-Sentence Answer

直接带隙材料里，导带底和价带顶在相同的 k 状态附近，电子复合更容易直接放出光子；间接带隙材料还要处理较大的晶体动量变化，所以更容易把能量交给声子和热。

## Why This Exists

AI 数据中心光模块经常同时出现 InP、GaAs、Si 和 SiPh。读者要先知道：这些词分属不同层级，背后对应有物理原因的材料分工。

## 先理解 k 空间：电子状态的"动量坐标系"

在讨论直接和间接之前，需要先理解"导带底和价带顶在不在同一个 k"是什么意思。

### k 是什么

实空间用 x, y, z 描述"电子在晶体里的哪个位置"。但晶体是周期结构——原子以固定间距重复排列。电子在这种周期势场中运动时，它的波函数满足布洛赫定理，由**波矢 k** 描述其传播特性：

```
ψ_k(r) = u_k(r) · e^(ik·r)
```

k 的方向代表电子波在晶体中的传播方向，|k| 代表波长的倒数（k = 2π/λ）。k 不是电子的真实动量 p=mv，而是**晶体动量** ℏk——在完美周期晶格中，ℏk 是守恒量。

### E(k) 图：从 k 空间看电子能量

对于晶体中的电子，能量 E 是 k 的函数。把 E 做纵轴、k 做横轴画出来，就是 E(k) 图——能带结构图：

```
E ↑（能量）
  │
  │   导带：E_c(k)
  │        ╱╲
  │       ╱  ╲____
  │      ╱
  │────╲────────────  E_g（带隙）
  │     ╲
  │      ╲____
  │           ╲
  │   价带：E_v(k)
  │
  └──────────────────→ k（波矢/晶体动量）
```

曲线上每个点代表一个电子状态——一个"在这个晶体里，动量为 ℏk 的电子，能量必然是 E(k)"的对应关系。这个映射由材料的原子种类和晶格结构决定，是材料的"指纹"。

曲线为什么是弯的？在自由空间，E = ℏ²k²/2m，是光滑的抛物线。在晶体中，周期势场改变了这个关系：某些 k 值处，电子波被晶格强烈反射（布拉格反射），形成驻波，能量发生跳变——这就是能带和带隙的起源。

### 导带底（CBM）和价带顶（VBM）

能带不是平线，而是弯曲的。两个最关键的点：

- **CBM（导带底）**：导带 E_c(k) 曲线的最低点——电子被注入导带后，通过发射声子逐级往下掉，最终在这里"休息"
- **VBM（价带顶）**：价带 E_v(k) 曲线的最高点——电子从这里起跳，因为这里离导带最近，跨越带隙需要的能量最小

带隙 E_g 严格定义为这两个特定点之间的能量差：E_g = E_CBM − E_VBM。几乎所有半导体光学性质都由这两个点的相对位置决定。

## 直接与间接：CBM 和 VBM 在 k 轴的相对位置

理解了 E(k) 图，直接/间接的区别就一目了然。

### 直接带隙：CBM 和 VBM 在同一 k 值

```
E ↑
  │
  │              ╱╲
  │             ╱  ╲
  │            ●    ╲       ● = CBM
  │            │     ╲
  │            │ E_g   ╲
  │            │        ╲
  │            ●         ╲   ● = VBM
  │           ╱╲          ╲
  │          ╱  ╲____  ____╲
  │         ╱       ╲╱
  │                    价带
  │
  └────────────┬─────────────→ k
          CBM 和 VBM 在同一竖线上
```

电子从 CBM 跳回 VBM：**竖直向下的箭头**。初态和末态 k 相同，动量自动守恒。光子带走能量 E_g，不需要声子帮忙。这是高效发光的基础。GaAs、InP、InGaAsP 都属于这一类。

### 间接带隙：CBM 和 VBM 在不同的 k 值

```
E ↑
  │
  │    导带
  │         ╲
  │          ╲____
  │               ╲
  │                ●____       ● = CBM
  │              ╱      ╲____
  │            ╱              ╲
  │          ╱                  ╲
  │        ╱       E_g            ╲
  │      ╱                          ╲
  │    ●                              ╲   ● = VBM
  │    ╲____                      ____╲
  │         ╲                    ╱
  │          ╲   价带           ╱
  │
  └──────────┬────────┬────────────────→ k
            VBM      CBM
           (k₁)     (k₂ ≠ k₁)
```

电子在 CBM 的 k ≠ 空穴在 VBM 的 k。跃迁不能竖直进行——因为 VBM 正下方的价带位置没有状态可去。电子必须从 k₂ 跳到 k₁，动量改变了 Δk。光子动量太小（k_photon ≈ 10⁷ m⁻¹ vs Δk ≈ 10⁹ m⁻¹），推不动，必须**一个声子**来填补这 Δk。

### 声子：晶格振动的一份能量

声子不是基本粒子，而是晶格振动的量子化单位——可以理解为一小份振动能量。典型的光学声子能量约 30–50 meV。

电子从 CBM 落回 VBM 时，动量账要平：

```
初态：电子 (k_CBM)
末态：电子 (k_VBM) + 光子 (k_photon ≈ 0) + 声子 (Δk)
```

声子提供了 Δk 的动量。但这是一个**二阶微扰过程**——需要电子、光子、声子三者同时耦合。量子力学上，其矩阵元远小于直接跃迁（只涉及电子-光子耦合）。这正是硅发光效率极低的根本原因——不是"不能"，而是辐射复合被其他通道（Auger 复合、SRH 复合）远远超过。

电子从导带高能位置跌落到 CBM 也走声子通道：每发射一个声子，电子损失 ~30–50 meV 能量，落到导带中更低的能级。经过几十次这样的发射（时间尺度 ~10⁻¹³ s），电子最终"冷却"到 CBM。这些声子被晶格吸收——宏观上就是材料变热。这也是光子能量超过带隙时，多余部分变成热而非光的微观机制。

### 直接/间接的对比

```
直接带隙：                   间接带隙：

    E ↑                          E ↑
      │                            │
      │    ●  ← 同一 k              │        ●  ← 这
      │    │                        │       ╱
      │    │ E_g                    │ E_g ╱  需要声子
      │    │                        │    ╱    帮忙横移
      │    ●  ← 同一 k              │   ●  ← 那
      │                            │
      └────────→ k                 └────────→ k

   跃迁：↓ 竖直                     跃迁：↙ 斜的
   动量：自动守恒                   动量：需要声子填补 Δk
   发光：高效                       发光：极低效
```

直接带隙通常更适合高效发光器件；间接带隙材料可以发光，但效率通常差得多。硅的辐射复合内量子效率在室温下约 10⁻⁶——每 100 万个电子-空穴对，只有 1 个产生光子，其余全部走非辐射通道产热。

## Engineering Implementation

这带来非常实际的分工：

- **GaAs**：适合 850 nm VCSEL、短距多模生态。
- **InP 相关 III-V 材料**：适合 1310 nm / 1550 nm 通信光源和探测。
- **Si**：适合 CMOS、硅光波导、调制和集成，但不适合直接作为高性能原生激光器。

后面讲外部 CW laser + SiPh 时，这个分工会反复出现：硅光 PIC 不等于硅自己承担所有发光任务。

## Key Metrics

- bandgap type: direct or indirect。
- emission wavelength range。
- radiative efficiency。
- non-radiative recombination probability。
- lattice match and defect density, later belongs to epitaxy chapter。

## Common Misconceptions

- 直接带隙不等于“自动就是好材料”。它只说明发光路径更有利。
- 间接带隙材料可以发光，但不适合作为高效原生光源。
- SiPh 不是“硅激光器路线”的同义词。SiPh 更常指硅平台上的光路、调制、复用和集成。

## Short Version

直接带隙更容易把电子空穴复合变成光子，间接带隙更容易把能量耗散到晶格振动。这个差异解释了为什么数据中心光源常用 III-V，而硅更多承担电子和光路集成。

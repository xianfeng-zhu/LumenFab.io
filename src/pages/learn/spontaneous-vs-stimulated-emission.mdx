## One-Sentence Answer

自发辐射产生随机光子，受激辐射复制已有光子的方向、相位和波长；激光还需要增益、反馈、约束和阈值。

## Why This Exists

“会发光”不等于“会激光”。LED、ASE、FP 激光器、DFB 激光器和外部 CW laser 都涉及电子空穴复合，但只有满足增益和反馈条件时，输出才会变成可用激光。

## 三件事要分清

在半导体有源区里，电子和空穴复合时可以释放能量。这个能量可能变成光子，也可能通过非辐射路径变成热。涉及光子的过程有三个，底层机制各不相同：

- **Spontaneous emission**：电子自己跳下来，发出随机方向、随机相位的光子。
- **Stimulated emission**：已有光子经过时，触发电子跳下来，发出一个与入射光子完全相同的光子（同频率、同相位、同方向、同偏振）。
- **Absorption**：光子被电子吃掉，电子从价带跳上导带，光子消失。

如果受激辐射强于吸收，就出现净 optical gain。只有再加上腔体反馈和模式筛选，激光振荡才会建立。

## 自发辐射的触发器：真空涨落

电子在导带、空穴在价带——这是一个高能态。系统倾向于回到低能态（电子填回价带），但为什么电子不"永远"停在导带？什么决定了它跳下来的时刻？

电磁场的基态不是"零能量"。根据不确定性原理 ΔE·Δt ≥ ℏ/2，真空的电磁场存在**零点涨落**——无数微小的"虚光子"在极短时间内出现和消失。这些涨落像随机噪声，不断扰动导带中的电子。在某个随机时刻，电子被扰动触发，跳回价带，往某个随机方向释放一个实光子。

这就是自发辐射的本质：**真空噪声敲门，电子随机应答**。正因为触发源是随机的，出来的光子也是随机的——方向随机，相位随机，时刻随机。只有频率是确定的（由 E_g = hν 锁定）。

## 受激辐射的放大器：玻色增强

受激辐射的本质区别在于：**不是真空噪声在敲门，而是一个真实光子在场**。

光子是玻色子。玻色子的统计特性是"喜欢扎堆"——一个电磁模式中已经存在的光子数越多，新光子进入同一模式的概率越大。这就是**玻色增强**效应。

用量子语言说：费米黄金法则给出的跃迁速率中，包含一个因子 (N_photon + 1)，其中 N_photon 是目标模式中已有的光子数。自发辐射对应 N_photon = 0（只有真空涨落的"+1"），受激辐射对应 N_photon ≥ 1（已有光子的贡献占主导）。

这就解释了受激辐射的核心特征——**光子克隆**：

```
入射光子（k₁, ν, φ₁, 偏振）→ 触发电子跃迁
    → 新光子选择进入同一模式（N_photon 大 → 概率大）
    → 出射光子（k₂=k₁, ν, φ₁, 偏振相同）
    → 一个光子进来，两个完全相同的光子出去
```

k 相同 = 波长相同、方向相同。这就是相干放大——光子不仅被复制了能量，还被复制了量子态。

## 吸收与增益的竞争

以上三个过程中，吸收和受激辐射的**微观截面完全相同**（爱因斯坦 B₁₂ = B₂₁）。这意味着一个光子穿过材料时，它被吸收的概率和触发受激辐射的概率，只取决于各自阵营里有多少"能参与"的电子：

```
受激辐射速率 ∝ N_c × (1−N_v) × (光子数 + 1)
吸收速率     ∝ N_v × (1−N_c) × (光子数)

净速率 ∝ (N_c − N_v)
```

其中 N_c 是导带某能态的电子占据概率，N_v 是价带对应能态的电子占据概率。

- N_c − N_v > 0：净受激辐射 → **增益**（光被放大）
- N_c − N_v < 0：净吸收 → **损耗**（光被衰减）
- N_c − N_v = 0：恰好透明

热平衡下，电子主要在价带（N_v ≈ 1, N_c ≈ 0），N_c − N_v < 0——吸收稳赢。要让增益大于吸收，必须**反转**这个关系：导带电子比价带同能态电子更多。这就是粒子数反转的条件——也是激光器阈值条件的物理根源。实现反转需要持续注入电流或泵浦光，具体机制见 [PN 结和载流子注入](../pn-junction-and-carrier-injection/)。

## Engineering Implementation

半导体激光器通常通过 PN 或 PIN 异质结构注入载流子。低电流时，它更像 LED 或 ASE 光源；超过阈值后，腔内特定模式被反复放大，输出功率明显增加。

这也是为什么激光器页面不能只画“电子掉下来发光”。真正的器件必须同时画出：

- carrier injection。
- active region。
- optical mode。
- cavity feedback。
- loss and output coupling。

## Key Metrics

- spontaneous emission rate。
- stimulated emission rate。
- absorption coefficient。
- material gain。
- threshold current。
- slope efficiency。

## Common Misconceptions

- 激光不是“更亮的 LED”。
- 出光方向由腔体反馈和波导模式筛选出来。
- 受激辐射会复制已有光子的方向和相位，但器件输出方向仍由腔体与波导共同决定。

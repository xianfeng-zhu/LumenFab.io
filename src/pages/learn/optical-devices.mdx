光模块、光互连芯片和光子集成电路（PIC）看起来复杂，但拆开来看，它们大多由几种基础光器件组合而成。这些器件本身不绑定特定材料——在硅光、InP、TFLN 或 SiN 平台上都能找到对应实现。理解它们的工作原理，是理解调制器、接收机和复用器的前提。

## 波导：光的“导线”

波导是集成光子学里最基础的构件。它的作用很简单：把光约束在一条预定路径里传输，就像电线约束电流一样。

### 结构与共通原理

最常见的波导由一个折射率较高的**芯层**（core）和包围它的低折射率**包层**（cladding）组成。光在芯层与包层界面发生**全内反射**（total internal reflection, TIR），被反复“折回”芯层内部，从而沿波导传播。

全内反射的前提是入射角大于临界角。临界角由芯层折射率 n₁ 和包层折射率 n₂ 决定：n₂ 越接近 n₁，临界角越大，光越容易逸出；n₂ 与 n₁ 差距越大，约束越强。这个差距称为**折射率对比度**（index contrast），它决定了波导能把光限制得多紧、弯曲半径可以做多小。

### 从光线到模式

用“光线在芯层里来回反弹”的图像可以理解约束，但波导真正关键的是光的波动性。只有那些在经过一次横向往返后**相位与自身保持一致**的电磁场分布，才能在波导里稳定传播。这些稳定的场分布就是**模式**（mode）。

每个模式可以用一个**传播常数** β 描述，它表示光沿波导方向传播的相位速度。工程上更常用**有效折射率** n_eff = β / k₀，其中 k₀ 是真空中的波数。n_eff 可以看作是光在波导里“感受到”的平均折射率，介于 n₁ 和 n₂ 之间。

模式的电场并不完全局限在芯层里：它会以指数形式伸入包层，形成**倏逝波**（evanescent tail）。倏逝波是定向耦合器、微环谐振器等器件能够工作的物理基础。

### 单模与多模

如果波导横向尺寸远大于光波长，或者折射率对比度很高，它会同时支持多个模式，称为**多模波导**。不同模式以不同的 n_eff 传播，会造成模式色散和脉冲展宽，不利于高速信号传输。

当波导尺寸或对比度降到一定程度，就只保留一个模式，成为**单模波导**。判断依据是归一化频率 V（也叫 V-number）：V 低于某个截止值时，高阶模式无法传播。高速 PIC 和光互连链路通常优先使用单模波导，以避免模式串扰和色散。

### 常见几何形态

按约束维度可以把波导分成几类：

- **平板波导**（slab waveguide）：只在厚度方向约束光，平面方向自由传播。它更像理论模型，也用于一些薄膜器件。
- **沟道波导 / 条形波导**（channel / strip waveguide）：在横向和厚度方向都约束光，是 PIC 里最常用的形态。
- **光纤**（optical fiber）：圆柱形波导，长距离通信的标准介质。

无论哪种形态，物理本质都一样：高折射率芯层 + 低折射率包层 + 全内反射 + 离散模式。

## 耦合器与分束器：把一束光分成多束

耦合器（coupler）或分束器（splitter）是一种无源波导器件，用来把一路光功率重新分配到多路，或者把多路光合并到一路。由于光路可逆，同一个结构既可以当分束器用，也可以当合束器用。

常见的实现有三类：Y 分支、定向耦合器和 MMI 耦合器。

### Y 分支

Y 分支是最直观的分束结构：一根输入波导缓慢分叉成两根输出波导。只要分叉角度足够小，光就会**绝热地**从单波导基模演化到双波导的偶对称超模，功率被均等地分到两个出口。

它的优点是结构简单、宽带、对工艺误差不敏感；缺点是分叉越平缓器件越长，过急的分叉又会引入损耗。Y 分支常用在只需要把光一分为二、不严格要求相位的场景。

```
输入 ──→    /──→ 输出 1
            \
             └──→ 输出 2
```

### 定向耦合器

定向耦合器由两根相互平行、间距极近（几百纳米）的单模波导组成。由于倏逝波重叠，两根波导中的光会发生能量交换。

把两根波导看作一个整体系统，它支持两种**超模**：偶对称模和奇对称模，它们的有效折射率略有不同。输入光同时激发这两种超模，它们以不同的相位速度传播；随着传播距离增加，两种超模时而同相、时而反相，导致光功率在两根波导之间周期性“跳动”。

如果耦合区长度等于耦合长度 L_c，光会完全从一根波导转移到另一根；如果长度等于 L_c / 2，则实现 50:50 分束。Cross 口与 Bar 口的功率随长度呈 sin² 和 cos² 关系。

```
         耦合区
输入 1 ──→───────→ 输出 1（Bar）
           ───────→ 输出 2（Cross）
输入 2 ──→
```

定向耦合器尺寸紧凑，但对波长、偏振和 gap 宽度比较敏感，常用于对分束比要求精确的地方。

### MMI 耦合器

MMI（Multimode Interference，多模干涉）耦合器使用一段较宽的多模波导区，输入光在这里激发多个横向模式。这些模式以不同速度传播，在特定距离上重新干涉，形成输入场的多个“自成像”。

利用这一特性，可以把一路输入复制成两路或多路输出，也可以实现 2×2 耦合。MMI 的主要优势是带宽较宽、工艺容差大，适合需要稳定 50:50 或 N×N 分束的场合；缺点是 footprint 通常比定向耦合器大。

### 三种方案怎么选

| 类型 | 分光原理 | 带宽 | 工艺容差 | 典型 footprint | 常见用途 |
|---|---|---|---|---|---|
| Y 分支 | 绝热模式演化 | 很宽 | 大 | 中 | 简单 1×2 分束、MZI 输入级 |
| 定向耦合器 | 倏逝场耦合 / 超模干涉 | 较窄 | 小 | 小 | 精确 3 dB 耦合、相干接收前端 |
| MMI 耦合器 | 多模自成像 | 宽 | 中 | 较大 | 宽带 1×2 / 2×2 耦合、光开关 |

## 光栅耦合器：把光引进和引出芯片

光栅耦合器解决的是一个界面问题：光纤里的光斑直径约 10 µm，而片上波导里的模式只有几百纳米。直接对接会因为模式尺寸和有效折射率严重失配而损失大量光。光栅耦合器通过**衍射**把大光斑和小模式桥接起来。

### 核心物理：动量匹配

片上波导模式的传播常数 β 很大，而光纤中光沿芯片表面方向的波矢分量 k₀ sin θ 很小。光栅在波导表面引入周期为 Λ 的折射率调制，产生一系列空间谐波，波矢为 β + m·2π/Λ。只要其中某一级谐波与光纤入射光的切向波矢匹配，光就能被耦合进波导：

k₀ sin θ + m·2π/Λ = β

这个条件把光栅周期、入射角和工作波长绑定在一起。改变其中一个，就必须重新设计另外两个。

### 两种等价图像

可以把光栅耦合器理解为：

- **漏波转换器**：波导里的导模进入周期性区域后变成“漏模”，一边沿波导传播，一边把能量辐射出去。
- **相控阵散射体**：每个光栅齿都是一个小散射源，它们辐射的子波在特定方向上相干叠加，形成出射光束。

由于光路可逆，同一个结构既能把光耦合进芯片，也能把光耦合出芯片。

### 效率与权衡

高效率光栅耦合器需要同时控制三个损失通道：

- **方向性**：让光主要向上辐射到光纤，而不是向下漏入衬底。
- **反射抵消**：表面反射不仅来自 Fresnel 反射，还包括漏波自身的反射分量；通过设计振幅和相位可以使两者相消。
- **模式匹配**：均匀光栅辐射场呈指数衰减，而光纤模式接近高斯分布，因此常采用**变迹**（apodization）让光栅 teeth 的耦合强度沿长度变化，以匹配光纤模式。

作为回报，光栅耦合器允许从芯片**顶部垂直耦合**，支持晶圆级光学探针测试和多通道光纤阵列，省去切割、抛光端面的工序。代价是带宽通常比端面耦合器窄，且对偏振和角度更敏感。

## 微环谐振器：一个闭合波导环

微环谐振器把一根波导弯成闭合圆环，并通过倏逝场与一条或多条总线波导耦合。光进入环后反复绕行；只有满足特定条件的波长才能在环里稳定增强。

### 谐振条件

谐振要求光在环内绕行一周的相位变化是 2π 的整数倍。用有效折射率 n_eff 和环长 L 表示，就是：

m λ_res = n_eff L

其中 m 是整数。相邻两个谐振峰之间的波长间隔称为**自由光谱范围**（Free Spectral Range, FSR），近似为：

Δλ ≈ λ² / (n_g L)

n_g 是群折射率。环越小，FSR 越大，这对密集波分复用（DWDM）系统很有吸引力。

### 全通与上下路

- **全通型**（all-pass）：只有一个总线波导。在谐振波长处，环内光与总线光发生相消干涉，透射谱出现一个凹陷；非谐振波长则几乎无损耗通过。
- **上下路型**（add-drop）：有两个总线波导。谐振波长在 through 口出现凹陷，同时被耦合到 drop 口输出。

### 关键指标

- **品质因数 Q**（Quality factor）：谐振峰频率与半高宽的比值，反映谐振的尖锐程度和能量存储能力。Q 越高，波长选择性越强，但也越怕温度和工艺漂移。
- **精细度 F**（Finesse）：FSR 与谐振线宽的比值，表示相邻峰之间的“精细”程度。
- **耦合状态**：根据环与总线之间的耦合强度和环内损耗的相对大小，可分为欠耦合、临界耦合和过耦合。临界耦合时全通结构的 through 口透射为零。

微环尺寸可以做得很小，因此是紧凑滤波器、WDM 解复用器和微环调制器的核心结构。

## Mach-Zehnder 干涉仪（MZI）

Mach-Zehnder 干涉仪是集成光子学中最基础的有源/可调器件结构之一，同时是电光调制器和光开关的共同基础。它的核心思想是把一束光劈成两路、在其中一路（或两路）改变相位、再让它们重新相遇——相遇时的相位差决定了能量往哪里走。

### 工作原理

```
         上臂（可调相）
         ┌──────────┐
输入 ──→ 耦合器      耦合器 ──→ Cross 口
         └──────────┘      └──→ Bar 口
         下臂（参考臂）
```

分三步：

1. **分束**：输入光在第一个耦合器（定向耦合器或 MMI）被均匀分成两束相干光，各带一半能量，分别进入上下两个波导臂。耦合器同时引入 90° 的固定相移，使无外加作用时的默认出口为 Cross 口。

2. **调相**：在一条臂（或两条臂同时、相反方向）上改变光的相位。相位怎么变取决于用什么材料——铌酸锂靠 Pockels 效应（加电压 → 折射率变 → 光程变）、硅靠载流子耗尽或热光效应、InP 靠量子阱 Stark 效应。不管机制是什么，效果是一样的：这一臂的光到达输出耦合器时的相位发生了变化。

3. **干涉**：两束光在输出端耦合器重新相遇。耦合区中波导间距仅几百纳米，倏逝波互相泄漏，形成统一的电磁系统——超模。两臂的相对相位差决定了激发哪种超模，进而决定了能量流向哪个出口。

### 输出特性

输出口的光功率随相位差 φ 呈正弦关系：

- φ = 0 → 光全部从 **Cross 口**输出（默认状态）
- φ = π → 光全部从 **Bar 口**输出
- φ 在中间 → 光在两个出口之间按 sin²(φ/2) 和 cos²(φ/2) 分配

让输出从 Cross 翻转到 Bar 所需的电压称为 **V_π**（半波电压）。V_π 越低，驱动越省电。

### 两种工作模式

同一个 MZI 结构，用不同的驱动方式可以实现两种完全不同的功能：

- **调制器**：用连续变化的电压驱动，把电信号波形按比例“印”到光载波上。实际光路中只取其中一个口作为调制信号输出，另一口通常用于功率监控或接终端吸收；输出电压和光输出强度的关系就是信号的调制曲线。
- **光开关**：只用两个离散电压（0 和 V_π），把光在两条路径之间来回切。切换速度取决于相位调制机制的响应时间。

### 推挽与行波电极

**推挽（push-pull）**：在两臂同时施加相反极性的电压，一臂相位增加、另一臂相位减少。同样的总电压下相位差翻倍，V_π 减半——这是降低驱动电压的标准工程手段。

**行波电极**：对于高速调制器（数十 GHz 以上），电信号沿电极传播的速度必须和光在波导里的速度匹配，否则电信号走过的不同位置会“看到”不同的瞬时电场，带宽被拖垮。行波电极将微波传输线设计为与光波导共面，使电信号和光信号同步传播——这是集成电光调制器做到 100 GHz 以上的工程基础。

### 跨材料通用性

MZI 本身不绑定材料——只要你能在波导上产生相位变化，就能做成 MZI。不同材料只是“调相”这一步的实现方式不同：TFLN 用 Pockels 效应（最快，fsec 级），Si 用载流子耗尽或热光（慢，ns–μs 级），InP 用 QCSE 或电吸收。MZI 的输出特性（正弦关系、V_π、Bar/Cross 逻辑）在所有平台上都一样。

## 阵列波导光栅（AWG）

阵列波导光栅（Arrayed Waveguide Grating, AWG）是一种无源平面波长复用/解复用器件，能把多个波长通道分开或合并。在光模块里，它是实现 DWDM/CWDM 集成的关键结构之一。

### 结构

AWG 由三部分组成：

1. **输入/输出波导**：连接外部光路。
2. **两个星形耦合器 / 自由传播区**（Free Propagation Region, FPR）：也叫 slab 区，相当于两个平板透镜，把输入波导端面的光发散/聚焦到输出端面。
3. **阵列波导**：位于两个 FPR 之间，由 N 根长度递增的波导组成，相邻波导长度差固定为 ΔL。

```
输入 ──→ 输入 FPR ──→ [ 阵列波导（长度递增 ΔL）] ──→ 输出 FPR ──→ λ₁ 输出
                                                           ├──→ λ₂ 输出
                                                           └──→ λ₃ 输出
```

### 工作原理

光从输入波导进入第一个 FPR 后发散，被阵列波导接收。由于相邻波导长度不同，光离开阵列时带有一个与波长相关的相位斜坡。第二个 FPR 把这个倾斜波前干涉聚焦到不同位置；不同波长聚焦到不同的输出波导，从而完成解复用。

相邻波导引入的相位差为 m·2π 时对应中心波长，m 称为**光栅级次**。AWG 的响应是周期性的，周期即为自由光谱范围 FSR；设计时需要确保工作波段落在同一个 FSR 内，避免不同波长在同一个出口叠加。

### 指标与应用

AWG 的关键指标包括插入损耗、通道非均匀性、串扰、通带形状以及对温度和偏振的敏感性。由于它完全是平面结构，可以用同一套光刻工艺与波导、探测器阵列集成，因此广泛用于：

- 相干/可插拔光模块中的 DWDM/CWDM 通道化
- 集成接收机：AWG + 光电探测器阵列
- 波长路由器、上下路节点
- 片上光谱仪、光信道监测

与薄膜滤波器或光纤布拉格光栅相比，AWG 的优势是通道数多、集成度高；劣势是对温度更敏感，通常需要温控或设计补偿。

## 小结

从波导、耦合器、光栅耦合器，到微环、MZI、AWG，这些器件构成了 PIC 和光模块的“基础元件库”。它们之间可以按功能堆叠：

- 波导 + 耦合器 → 分束/合束网络
- 波导 + 调相段 + 耦合器 → MZI 调制器/开关
- 波导弯成环 + 耦合区 → 微环滤波器/调制器
- 波导阵列 + 星形耦合器 → AWG 复用/解复用器

它们的具体材料实现（Si、InP、TFLN、SiN）会影响损耗、带宽和驱动方式，但物理结构和工作原理是跨平台共通的。理解了这些基础器件，再看具体的激光器、调制器、接收机和光模块，就会清楚它们是如何一层一层组合起来的。

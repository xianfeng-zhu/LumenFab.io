## 8. 测试与筛选

激光器芯片进入后续组装之前，需要证明它在目标电流、目标温度和目标波长窗口内能够提供稳定输出。测试会将前面所有制造变量转化为数据：外延厚度和组分、光栅周期、脊形宽度（ridge width）、接触电阻、绝缘开窗、解理质量和端面镀膜，最后都会反映到 I-V、L-I、光谱、温漂、噪声和老化表现中。

### 8.1 测试阶段与顺序

激光器芯片的测试不是一次完成的，而是分布在制造流程的多个节点上。每经过一道测试，就排除一批不良品，减少后续工序的浪费：

| 阶段 | 形态 | 主要测试内容 | 目的 |
|------|------|-------------|------|
| 晶圆级（wafer-level） | 完整晶圆上的器件 | 仅电学预检（开路/短路/漏电），光学测试需要刻蚀端面才能做 | 快速排除明显坏片 |
| Bar 级（bar-level） | 解理后的 bar 条 | L-I-V、光谱（中心波长 / SMSR）、外观检查 | 在镀膜后立即排除端面缺陷和严重性能偏差 |
| Chip 级（chip-level） | 单颗 die | 完整 LIV + 光谱 + RIN + 远场 | 分档和最终 pass/fail 判定 |
| CoS 级（chip-on-submount） | 芯片已贴装到热沉 | 重复 LIV + 光谱，确认贴装后参数无漂移 | 排除贴装引入的热阻异常或损伤 |
| 模块级（module-level） | 封帽后模块 | 全温测试 + burn-in + 老化筛选 | 最终出厂前的可靠性验证和寿命筛选 |

每一步测试的逻辑是：**测试成本越高的步骤，越要放在后面**——先用便宜的方法筛掉差的，让贵的测试只测已经预筛过的芯片。

### 8.2 为什么需要测试

同一片晶圆、同一套版图上的芯片也会存在离散性。晶圆中心和边缘的外延厚度可能不同，光栅周期和刻蚀深度会有纳米级偏差，金属接触和绝缘开窗会带来电阻或漏电差异，解理和镀膜也会让端面反射率和端面吸收不同。

测试的作用是判断这些差异是否仍落在设计窗口内。对激光源来说，合格芯片需要同时满足目标功率、目标波长、单模稳定性、效率、噪声、温度窗口和早期可靠性要求。

### 8.2 外观与电学检查

测试通常先排除明显坏片。显微检查会观察崩边、裂纹、污染、金属剥落、焊盘（pad）损伤、端面缺陷和镀膜异常。电学预检会查看开路、短路、反向漏电、低电流漏电、开启电压异常和串联电阻异常。这些项目可以及早暴露绝缘层问题、侧壁漏电、结缺陷、接触不良、ESD 损伤或电流阻挡结构异常。

这一层检查与第 4 节的内容直接相关：电流注入位置、欧姆接触、钝化和电流约束做得如何，最早会在 I-V 行为和漏电测试中显现。

### 8.2 L-I-V 测试

**测量对象**：光功率（L）、驱动电流（I）、二极管电压（V）。从低电流扫描至目标工作电流，同时记录三个物理量。对生产线上批量测试，通常使用脉冲模式（低占空比，如 0.1–1%）以最小化自发热，确保结温接近热沉设定温度；研发或抽检时也做 CW 测试来观察热效应对 L-I 曲线形状的影响。

**从 L-I 曲线提取的六个关键量：**

| 参数 | 怎么提取 | 反映什么 |
|------|---------|---------|
| 阈值电流 `Ith` | L-I 曲线上方线性段的延长线与电流轴的交点（线性拟合法），或 d²L/dI² 的峰值位置（二阶导数法） | 增益能否补偿总损耗。Ith 偏高说明外延增益不足、波导损耗过大、端面反射偏离设计或漏电过大 |
| 斜率效率 `SE` | L-I 曲线上方线性段的斜率，单位 W/A | 每增加 1 A 电流能多输出多少光功率。影响目标功率点的驱动电流需求和发热 |
| 串联电阻 `Rs` | V-I 曲线在阈值以上的斜率，d V / d I | 欧姆接触和体电阻。Rs 偏高会增加焦耳热，降低 PCE 并抬高结温 |
| 开启电压 `Vf` | V-I 曲线在 Ith 附近的截距 | p-n 结内建电势和接触势垒 |
| 扭折 `kink` | L-I 曲线线性段上的台阶或斜率突变 | 横向模式跳变、电流扩散异常或光栅反馈变化。通信激光器的 kink 需要在工作电流范围内完全不存在 |
| 热滚降 `thermal rollover` | 高电流段光功率弯折下行 | 结温过高导致增益下降，载流子泄漏加剧。滚降点与 CW-DFB 的最大可靠输出功率直接相关 |

**转换效率**：PCE（功率转换效率）或 WPE（电光转换效率）= 光输出功率 /（电流 × 电压）。注意它的峰值通常出现在中低电流段（I ≈ 2–3 × Ith 附近），而不是最大输出功率点。因为高电流下串联电阻损耗和热效应开始主导，电输入大部分变热而非光。对 CPO 场景，激光器的 PCE 直接决定光引擎的功耗预算，是一个关键系统级指标。

**CW vs 脉冲测试**：脉冲测试（~1 μs 脉宽，0.1% 占空比）能抑制自发热，测到的是"近室温"的 Ith 和 SE。CW 测试会看到 Ith 因结温升高而上移、SE 因热效应而降低、以及滚降点的位置。CW 和脉冲之间的差异本身就是热阻和散热能力的一个间接信号——差异越大，芯片的散热路径越紧张。

### 8.2 光谱测试

光谱测试用高分辨率光谱仪（OSA，典型分辨率 0.01–0.1 nm）采集激光器的输出光谱，从中提取三个核心指标：

**中心波长**：通常取光谱功率加权平均或峰值波长。对 CWDM/LAN-WDM/DWDM 应用，中心波长必须落在指定通道窗口内（例如 O 波段 CWDM4 为 1271/1291/1311/1331 nm，每通道公差约 ±6.5 nm；DWDM 精度要求更高）。波长偏差可能来自光栅周期的工艺偏差、外延厚度中心值偏移、或温度控制未到目标。

**SMSR（边模抑制比）**：定义为

```text
SMSR = 10 × log₁₀(P_main / P_side)
```

其中 `P_main` 是主模峰值功率，`P_side` 是最强边模的峰值功率。SMSR 反映了 DFB 光栅选模的有效性和单模纯度。

| SMSR | 水平 |
|------|------|
| < 30 dB | 不合格——边模过强，模式分配噪声和邻道串扰不可接受 |
| ≥ 35 dB | 及格线——通信级 DFB 的常见筛选阈值 |
| ≥ 40 dB | 良好——主流商用 DFB 的保证最小值 |
| ≥ 50 dB | 优秀——增益耦合或优化相移设计的器件 |

**模式跳变检测**：在不同电流和温度下重复采谱，观察主模是否在纵模间跳跃。即使某一点 SMSR 合格，如果在工作窗口内出现了模式跳变（主模从一个纵模位跳到另一个），说明光栅选模不够稳定——通常是 κL 过低、端面残余反射太大或温度窗口内有效折射率漂移过量。量产筛查中会在电流-温度网格上采谱，绘制模式稳定性图（mode stability map）。

**波长-电流和波长-温度系数**：典型的 1550 nm InP DFB 的 dλ/dT 约 0.1 nm/°C，dλ/dI 主要来自热效应。这两个系数是后续 TEC 设计和波长锁定电路的基础输入。

### 8.2 RIN 测试

RIN（Relative Intensity Noise，相对强度噪声）描述激光器输出光功率的随机涨落程度，是衡量"激光器有多安静"的核心指标。定义为单位带宽内光强噪声功率与平均光功率平方之比：

```text
RIN = ⟨δP²⟩ / (P_avg² × Δf)   [单位：1/Hz 或 dB/Hz]
```

**为什么重要**：RIN 直接贡献接收端的光信噪比。高 RIN（噪声大）意味着即使发射功率够，信号本身已经自带噪声——这在高数据速率（>100 Gbps PAM4）下尤其致命，因为 PAM4 的眼图裕量比 NRZ 小得多，对噪声容忍度极低。

**测量方法**：激光器输出经光隔离器后耦合到高速光电探测器，探测器输出的电信号经偏置 T 分离直流和交流分量，交流部分经低噪 RF 放大器后送入 RF 频谱分析仪。测量时需要扣除热噪声和散粒噪声基底。

**典型值**：

| 条件 | RIN (dB/Hz) |
|------|------------|
| 近阈值 | −120 至 −130（较高噪声） |
| 正常工作电流、CW 条件 | −150 至 −158 |
| 优化偏置 + 良好封装 | −160 至 −170 |
| 存在外部光反馈（相干坍缩） | 严重退化至 −107 以下 |

对 AI 数据中心光互连中的 CW-DFB 光源，通常要求 RIN ≤ −150 dB/Hz 在工作电流范围内全程满足。RIN 在弛豫振荡频率附近会出现峰值，因此高速 PAM4 调制场景还需要关注 RIN 谱形，确保弛豫峰不落在信号带宽内。

### 8.2 远场与光束质量

边发射激光器不是各向同性光源。垂直方向的有源区厚度仅数十至数百纳米，光从这么窄的出口衍射出来，形成一个大发散角的"快轴"；水平方向的波导宽度通常 2–5 μm，对应一个相对窄的"慢轴"。

| 参数 | 典型范围 | 含义 |
|------|---------|------|
| 快轴发散角 θ⊥ | 25–60° (FWHM) | 垂直方向衍射角度。由外延层波导设计决定 |
| 慢轴发散角 θ∥ | 6–12° (FWHM) | 水平方向角度。由脊宽或 BH 条宽决定 |
| 远场光斑 | 椭圆形 | 快轴宽、慢轴窄的椭圆——直接影响准直透镜的 NA 和耦合效率 |
| 偏振消光比（PER） | 边发射激光器通常为 TE 偏振主导，PER ≥ 20 dB | 对偏振敏感耦合（如光栅耦合器）至关重要 |

远场测量通过旋转探测器或使用大 NA 透镜 + 相机采集，从角分布曲线中提取 FWHM 发散角。快轴/慢轴角度直接决定第一片准直透镜的数值孔径选择和耦合损耗预估。

### 8.2 温度特性测试

激光器对温度的高度敏感性已在之前各小节反复提及。温度特性测试的目的不是再看一遍单点性能，而是**量化所有关键参数随温度变化的速率**，为系统热设计和 TEC 选型提供数据。

| 参数 | 温度敏感度 | InP DFB 典型值 |
|------|-----------|---------------|
| 中心波长 dλ/dT | 主要来自折射率变化 | ~0.1 nm/°C |
| 阈值电流 T₀ | Ith(T) = I₀ · e^(T/T₀) | InGaAsP/InP：55–70 K；AlGaInAs/InP：~90 K；越高越好 |
| 斜率效率 T₁ | η(T) = η₀ · e^(−T/T₁) | ~80–120 K |
| 输出功率 dP/dT | 综合效应 | ~−0.03 至 −0.05 dB/°C |

**T₀ 的测量**：在多个稳定温度点（如 20°C、40°C、60°C、80°C）记录 L-I 曲线，提取每个温度点的 Ith，拟合 ln(Ith) vs T 得到 T₀。测量时使用脉冲模式抑制自发热，确保结温接近热沉温度。T₀ 本身也是温度的函数——不同温区由不同损耗机制主导，T₀ 并不恒定。

### 8.2 老化筛选

老化筛选（burn-in）是通信激光器进入封装之前的一道必做工序。它将芯片在高温、高电流下运行数百小时，加速暴露早期缺陷，让"会在早期死掉的芯片"在出厂前就先死掉，不进入系统。

**筛选条件**（参照 Telcordia GR-468 和行业惯例）：

| 参数 | 典型条件 |
|------|---------|
| 温度 | 85–100°C（case 温度） |
| 电流 | 额定工作电流或更高（如 1.2× I_op） |
| 持续时间 | 100–500 小时（100% 出货筛选）；更长至 2000–5000 小时（批次可靠性鉴定） |
| 监测频率 | burn-in 前后及过程中定期记录功率、电压、光谱 |
| 失效判据 | Ith 漂移 > 10%、输出功率下降 > 1 dB、SMSR 退化 > 3 dB |

**物理加速效应**：高温高电流加速了端面氧化、金属扩散、位错攀移/滑移和缺陷增长。Arrhenius 模型（激活能 Ea ≈ 0.4–1.0 eV）用来关联老化时间和等效工作寿命——例如 100°C / 100 小时的筛选可能等效于常温下数千小时的工作应力。

**关键区别**：burn-in 是**筛选工具**——它排除早期失效（infant mortality），给出的是"这批芯片里哪些可以在系统中用"的判断。burn-in 的退化趋势可以提供寿命的定性参考，但**不能直接等同于额定寿命**——寿命预测需要更长时间的加速老化测试（>5000 小时）和 Weibull 统计分析。

### 8.3 对器件的影响

测试结果首先用于 pass / fail：芯片是否满足功率、电压、阈值、波长、SMSR、噪声和温度窗口要求。进一步还会进入分档：按波长通道、输出功率、工作电流、效率、温度余量、RIN、老化漂移等指标，将芯片分到不同应用等级。

这些数据也会反向服务工艺。晶圆图（wafer map）、条图（bar map）和批次统计可以显示异常是否集中在晶圆边缘、某个曝光区域、某个刻蚀批次、某个解理批次或某次端面镀膜中。测试将制造过程中的微小差异转化为可量化数据，筛选和分档则决定哪些芯片可以进入封装，哪些结果要反馈给外延、光栅、波导、电极、解理和镀膜工艺。

更完整的晶圆级测试（wafer-level test）、已知合格芯片（known-good-die）、封装级测试（package-level test）和模块级老化筛选见 [Manufacturing and test](../../manufacturing-test/)。

### 8.4 量产壁垒

芯片测试与筛选的壁垒，在于能否有效量化芯片间的离散性，并将测试数据反馈给工艺改进。激光器测试设备、夹具、温控、光谱仪和老化系统本身都可以买到；难点在于用稳定、可比较、吞吐量足够的测试流程，将每颗芯片的电学、光学、光谱、噪声、温度和老化表现转化为可执行的筛选规则。

真正有价值的测试体系通常包含三层能力：第一，测试项目覆盖足够全面，能够识别阈值、效率、串联电阻、波长、SMSR、RIN、滚降、模式跳变（mode hop）和早期退化；第二，分档规则能将不同芯片匹配到合适应用，避免把所有差异简单处理成报废；第三，晶圆图、条图、批次统计和失效分析能反向定位外延、光栅、刻蚀、电极、解理或镀膜问题。测试壁垒来自数据质量、统计模型、工艺反馈速度和长期积累的判断标准。

## 9. 器件评价指标

外延、波导、DFB 光栅、电流注入、端面和筛选流程，最后都会归结为一组可测指标。下表是 CW-DFB 光源（~1310 nm O 波段）用于硅光引擎时的典型指标范围，来自 Coherent/Lumentum 公开产品规格和 Meta CPO 白皮书的综合参考：

| 指标 | 典型范围 | 筛选阈值（参考） | 下游影响 |
|------|---------|----------------|---------|
| 中心波长 | 1310 ± 2 nm | 1310 ± 6.5 nm（CWDM4 通道） | WDM 通道匹配、微环谐振对准 |
| 输出功率（CW, 25°C） | 80–120 mW | ≥ 70 mW @ I_op | 链路预算、分光比 |
| 阈值电流 Ith | 8–15 mA | ≤ 20 mA | 驱动电路偏置点、待机功耗 |
| 斜率效率 SE | 0.25–0.40 W/A | ≥ 0.20 W/A | 目标功率所需电流 |
| SMSR | 40–55 dB | ≥ 35 dB | WDM 邻道串扰 |
| RIN | −155 至 −162 dB/Hz | ≤ −150 dB/Hz（工作电流范围） | 接收端信噪比、PAM4 眼图裕量 |
| 线宽 | 100 kHz – 2 MHz | ≤ 5 MHz | 相干通信调制格式 |
| PCE / WPE | 15–22%（峰值） | ≥ 12% @ I_op | 光引擎功耗预算 |
| 快轴发散角 θ⊥ | 35–55° (FWHM) | 设计窗口内 | 准直透镜 NA |
| 慢轴发散角 θ∥ | 8–12° (FWHM) | 设计窗口内 | 耦合对准容差 |
| 偏振消光比 PER | 18–25 dB | ≥ 15 dB | 偏振敏感耦合（光栅耦合器） |
| dλ/dT | 0.08–0.12 nm/°C | ≤ 0.12 nm/°C | TEC 需求和波长锁定 |
| T₀ | 55–90 K | ≥ 50 K | 高温下功率余量 |
| Burn-in 功率漂移 | < 0.3 dB（500 h, 100°C） | < 1 dB | 链路寿命预算中的衰减预留 |

这些指标之间并不独立。输出功率提高 → 端面光功率密度和结温上升；结温上升 → 增益峰和中心波长移动 → dλ/dT 叠加、SMSR 可能退化；串联电阻偏高 → 更多电输入变焦耳热 → PCE 下降 → 散热压力 → 结温再升。因此器件评价必须综合考量功率、波长、噪声、效率、温度和可靠性的窗口重叠情况。

## 10. 从芯片到系统

### 10.1 封装接口

芯片测试结束后，合格裸芯片（die）将一组边界条件提供给封装设计。封装设计需要根据裸芯片的光学、电学、热学和可靠性数据，确定耦合路径、驱动窗口、散热结构和筛选流程。光源放在光引擎内部、封装边缘或前面板外置模块中，属于封装与系统布局问题，详见 [Package integration](../../packaging/)。

| 接口类别 | 传给封装的主要参数 | 封装侧需要处理的问题 |
|---|---|---|
| 光学参数 | 输出功率、中心波长、SMSR、RIN、发散角、远场光斑、偏振方向、端面镀膜类型、反馈容忍度 | 透镜如何选择，光纤或 PIC 如何对准，耦合效率能达到多少，返回光是否需要额外抑制。 |
| 电学参数 | 阈值电流、额定工作电流、最大允许电流、工作电压、串联电阻、ESD 敏感性 | 驱动电流范围、软启动、过流保护、电压裕量和监控电路如何设定。 |
| 热学参数 | 功耗、PCE / WPE、热阻、波长温度系数、功率温度曲线、最高允许结温 | 是否需要 TEC，热沉和贴装材料如何选择，封装底座热阻需要控制到什么水平。 |
| 可靠性参数 | burn-in 结果、参数漂移、失效模式分布、端面和镀膜风险、批次和 wafer map 数据 | 哪些裸芯片可以进入贴装，哪些批次需要加严筛选，后续组装良率和返修风险如何估计。 |

对 DFB 激光器来说，封装热设计同时承担功率稳定和波长稳定两项任务。芯片温度变化会让中心波长漂移，也会改变阈值、斜率效率和输出功率。对 CW-DFB 光源来说，封装还要尽量减少返回光、热点和长期应力，因为这些因素会影响 RIN、SMSR、功率退化和寿命风险。

经过测试和筛选后，封装前通常希望拿到 known-good-die（KGD），也就是已经通过基本电学、光学和早期可靠性筛选的合格裸芯片。封装、耦合、封帽和模块测试的成本通常高于裸芯片筛选成本，因此在进入贴装之前先排除异常裸芯片，可以减少后续损失。

### 10.2 系统架构与激光源摆放

激光源在系统中的物理位置，是系统架构设计的第一项决策。当前行业主要有两种路线：

- **ELSFP 外置**（OIF ELSFP-02.0，2024 年发布）：激光源放在前面板可插拔模块中，通过保偏光纤把连续波光送到靠近 ASIC 的硅光引擎。激光器在自己独立的散热环境下工作（~25–50°C），对 T₀ 和 PCE 的要求相对常规。最大好处是可现场替换——激光器是整个链路中最可能先衰退的器件。
- **On-Package CPO**：激光器或光引擎直接坐在 switch ASIC 基板上，承受 70–100°C+ 的局部高温。这对激光器的 T₀、PCE、波长稳定性和寿命都是最严苛的考验。

两种路线的系统约束差异显著，但不管选哪种，激光器芯片的出厂参数——输出功率、T₀、RIN、SMSR、PCE、老化漂移——在架构设计的第一步就会被硬约束卡住。激光器的"出身"决定了系统能在哪种架构下安全运行。更详细的光源摆放和封装架构讨论见 [Package integration](../../packaging/)。

**ELSFP 外置光源 ≠ 随便一颗 CW-DFB 就行。** NPO 架构中，ELSFP 模块里的 CW 激光器需要满足一组严格的工程指标。这些指标不是独立存在的——参数之间有耦合，任何一项掉队都会沿链路向下传导，最终体现为链路预算不足或误码率恶化。

**核心光学参数要求：**

| 参数 | 典型要求 | 为什么重要 |
|------|---------|-----------|
| 波长 | O-band 1310 nm（CWDM4: 1270/1290/1310/1330 nm；DWDM: 200 GHz 栅格） | 硅波导在 O-band 透明；1310 nm 是单模光纤零色散窗口，啁啾-色散互作用最小 |
| 输出功率 | +17 ~ +23 dBm/通道（HP~UHP），取决于分光路数 | NPO 光路有 2 个光连接点（ELSFP 盲配 + 引擎输入），外加板上 PM 光纤衰减和 PIC 内部 1×N 分光损耗。8 路分光（1×8 splitter，理论 9 dB）后每通道功率骤降，必须高起点 |
| RIN（相对强度噪声） | < −145 dB/Hz（≤ −150 dB/Hz 更优） | RIN 直接转化为接收端 SNR 退化。112 Gbps PAM4 眼图对强度噪声极度敏感——RIN 从 −150 退化到 −140 dB/Hz，链路功率预算可能被吃掉 1–2 dB |
| 线宽 | < 500 kHz（IM-DD 场景）；< 100 kHz（相干场景） | IM-DD 系统中线宽主要影响啁啾-色散互作用；未来相干精简方案对线宽的约束更严 |
| SMSR（边模抑制比） | > 30 dB | WDM 系统中邻道串扰的物理来源。一个边模就是邻道的一个噪声源 |
| PER（偏振消光比） | > 15 dB | 硅光调制器（MZM、MRM）对输入偏振态敏感。ELSFP 盲配连接器、板上 PM 光纤弯曲、引擎输入耦合器每个都可能引入微小偏振旋转，累积后不可忽略 |
| 波长稳定性 | ±2.5 pm（约 ±0.5 GHz @ 1310 nm） | MRM 共振峰半高宽可能只有几十 GHz——光源波长漂出工作窗口，调制效率骤降 |
| 波长温漂 | 需 TEC 主动控温（双 TEC 为高端标配） | DFB 波长温漂 ~0.1 nm/°C。不控温时前面板 0–60°C 范围意味着 6 nm 漂移，远超 WDM 栅格容限 |
| 反馈容忍度 | 内置光隔离器（>30 dB 隔离度） | DFB 对外部反射极其敏感——光路上每个连接点的 Fresnel 反射都可能返回腔体，导致 RIN 暴涨（相干坍缩效应），极端情况从 −160 dB/Hz 退化至 −107 dB/Hz 以下 |

**OIF ELSFP 功率等级**（OIF-ELSFP-02.0 定义九档，每档公差 ±1.5 dB）：

| 等级 | 缩写 | 功率/通道 | NPO 适用性 |
|------|------|---------|-----------|
| Low Power | LP | +11 dBm（~13 mW） | 仅小端口数 |
| Medium Power | MP | +14 dBm（~25 mW） | 中等 |
| High Power | HP | +17 dBm（~50 mW） | ✅ 常见选择 |
| Very High Power | VHP | +20 dBm（~100 mW） | ✅ 充裕 |
| Ultra High Power | UHP | +23 dBm（~200 mW） | 大端口数或高损耗场景 |
| Super High Power | SHP | +26 dBm（~400 mW） | 过剩（大端口数、高损耗、光分路极多时用） |

NPO 通常选择 HP 或 VHP 等级。同等端口规模下，CPO 因多出一个封装级耦合界面（光损耗高 2–3 dB），可能需比 NPO 高一档功率等级。详见 [封装集成 §3.6](../../packaging/#36-外置-elsfp-下npo-与-cpo-对激光器的要求)。

**系统级要求**（OIF ELSFP-02.0）：

| 要求类别 | 具体内容 |
|---------|---------|
| 电接口 | 3.3V 单电源，最大 9 A 持续电流，host 侧供电噪声 ≤25 mV RMS（10 Hz–10 MHz） |
| 光连接器 | 盲配 MT 插芯，保偏光纤，8° 斜角抛光端面；可选气隙插芯（~9 μm spacer + AR 镀膜，反射率 ≤0.5%） |
| 管理协议 | CMIS 5.1，支持 DDM（数字诊断监控）、功率监测、故障隔离 |
| 激光安全 | 上电序列：先低功率（&lt;15 dBm）检测链路损耗 → 确认合格后升全功率 → interlock 断开 250 ms 内执行自动功率衰减（APR）。系统级 IEC 60825-2 Hazard Level 1 |
| 机械尺寸 | OSFP 风格外壳，前面板外露 ≤127 mm（5 英寸），1RU 最多 16 个模块，支持 belly-to-belly 双面配置 |
| 环境 | 工作壳温 0–60°C；温度循环（−40~85°C）、湿热（85°C/85%RH）、热冲击测试 |
| 可更换性 | 前面板热插拔，现场更换，无需动交换机内部。更换后管理系统重新识别和校准 |

> **为什么必须是 CW（连续波），有没有脉冲型外置光源？** 数据中心光互连没有。原因是五重硬约束：（1）外部调制需要一个持续稳定的光载波——调制器是"光开关"，输入光如果本身在闪烁，开关就没有意义；（2）NRZ / PAM4 格式要求光载波连续存在，脉冲源的脉冲间幅度抖动叠加在 PAM4 四电平上会直接闭合眼图；（3）脉冲越短光谱越宽，WDM 栅格中会溢出到邻道；（4）脉冲激光的直接调制带宽远低于 CW（~6 MHz vs ~100 MHz 量级），无法跟上 112 Gbps PAM4（56 GBd）的速率；（5）IEEE 802.3 和 OIF ELSFP 的所有标准均基于 CW 光源假设。脉冲光源在光通信中的存在场景是长距离孤子通信、OTDM 和自由空间光通信——不是数据中心。
>
> **光频梳（comb laser）不等于脉冲光源。** 光频梳在时域上可能表现为脉冲序列，但在数据中心应用中，它作为多波长 CW 源使用——通过光谱滤波将不同梳齿分开，每一路滤波后恢复为稳定的 CW 单波长输出，再各自送入调制器。到调制器输入端仍然是 CW 光。

### 10.3 可插拔光模块：激光器在壳子里

§10.2 讲的两种路线——ELSFP 外置和 On-Package 内置——都属于 CPO 或其变体。它们目前合计占数据中心光互连出货量的不到 1%。2025–2026 年超过 97% 的出货仍是**前面板可插拔光模块**（QSFP-DD / OSFP / QSFP28 等形态）。这一类模块的激光器封装在金属壳体内，与 DSP、driver、TIA、调制器和连接器共享同一块 PCB，是整个光模块的一部分。模块故障时整体更换，激光器不单独维护。

可插拔模块按传输距离和数据速率分挡，不同挡位对应不同的激光器方案：

**SR（Short Reach，~100 m，多模光纤）—— VCSEL 阵列。**

| 属性 | 内容 |
|------|------|
| 器件 | VCSEL（vertical-cavity surface-emitting laser，垂直腔面发射激光器） |
| 波长 | 850 nm |
| 材料平台 | GaAs |
| 调制方式 | 直接调制——驱动电流直接加载数据信号，光从芯片表面垂直出射 |
| 典型接口 | 400G SR8 / 800G SR8，8 通道并行，MPO-16 连接器 |

VCSEL 光从表面垂直出射，晶圆级即可测试，不需要切割端面。制造成本在所有半导体激光器中最低，功耗也最小。代价是 850 nm 在多模光纤中衰减和色散都大，距离被限制在约 100 m。它是数据中心内部同机架或相邻机架短距互连的绝对主力。

**DR / FR / LR（500 m–10 km，单模光纤）—— 三条技术路线。**

可插拔单模模块的激光源不是只有一种。以下三条路线共存，各有自己的工程取舍。

*路线一：DML（directly modulated laser，直接调制激光器）。*

InP DFB 激光器，驱动电流直接随数据信号摆动，激光器输出光强跟着变。结构最简单——一颗 DFB 芯片同时承担发光和调制两项任务，不需要额外的调制器。缺点是高速下啁啾（chirp）严重：电流变化导致有源区折射率变化，输出波长在调制过程中摆动，脉冲经光纤色散后展宽，远距离下眼图闭合。早期 100G DR 和部分 400G DR4 用 DML，200G/lane 以上逐渐被 EML 和 SiPh 替代。

*路线二：EML（electro-absorption modulated laser，电吸收调制激光器）。*

一颗 InP 芯片上单片集成两段结构：前段是 CW-DFB 激光器（持续输出稳定光），后段是电吸收调制器（EAM，通过外加电压控制材料吸收边，光通过或吸收）。DFB 段不碰数据，数据加在 EAM 段上——啁啾比 DML 低一个数量级。CWDM4 EML 方案做四颗不同波长的 EML 芯片（1271 / 1291 / 1311 / 1331 nm），每颗独立调制一个通道，四路经 MUX 合波进一根单模光纤。400G FR4 / LR4 和 800G FR4 大量使用此方案。

*路线三：SiPh + CW-DFB 激光器（增长最快）。*

激光器和调制器用不同材料平台：激光器是 InP CW-DFB 芯片（提供连续波光），调制器做在硅光芯片上（MZM 或 MRM）。模块内部的物理布局大致为：PCB → DSP → driver/TIA → SiPh PIC ← CW-DFB 芯片（通过 edge coupler 耦合进硅波导）→ 光纤连接器。CW 光进入硅波导后被 splitter 分成多路，每路进入一个调制器加载数据，调制后的信号光再经 edge coupler 送出光纤。

激光器在模块壳体内的位置是固定的——与 PIC 共享同一块子基板，通过 edge coupler 或透镜对准。可插拔模块的外壳散热（笼体上方压接散热器，通过模块顶面 TIM 导出热量）同时带走激光器、DSP 和 driver 的热量。由于空间紧凑，模块内部通常不加 TEC，激光器在无制冷条件下工作，结温可能达到 70–85°C。

| | VCSEL（SR） | DML（InP DFB） | EML（InP DFB + EA） | SiPh + CW-DFB |
|---|---|---|---|---|
| 波长 | 850 nm | 1310 nm | 1310 nm（CWDM4） | 1310 nm |
| 调制 | 直接调制 | 直接调制 | 外部调制（EA，单片集成） | 外部调制（MZM / MRM，硅光芯片） |
| 优势 | 成本最低、功耗最低、晶圆级测试 | 结构最简单、器件数最少 | 啁啾远低于 DML，适合更长距 | 调制器带宽高、集成度高、利于多通道 |
| 劣势 | 多模光纤限制距离 ~100 m | 高速啁啾限制距离 | 成本高于 DML | 模块内多一颗激光器芯片，耦合和装配步骤多 |
| 典型应用 | 400G SR8 / 800G SR8 | 100G DR，早期 400G DR4 | 400G FR4 / LR4，800G FR4 | 400G DR4 / FR4，800G DR8 / FR4，1.6T |
| 增长趋势 | 稳定存量 | 逐步被替代 | 成熟稳定 | 增长最快（2025 年约占可插拔出货 30%） |

**可插拔模块对激光器芯片的要求，和 ELSFP 有什么不同？**

同样是 InP CW-DFB 芯片，装在可插拔模块壳体内和装在前板 ELSFP 模块内，对芯片本身的功率、RIN、SMSR、T₀ 要求是同一量级。核心差异在两点：

第一，**热环境**。可插拔模块内部空间紧凑，DSP 和 driver 都在旁边发热，激光器在无 TEC 条件下结温可能达到 70–85°C。ELSFP 模块内部只有激光器和监控电路，热源少，散热设计更从容，结温通常可控制在 50°C 以下。同一颗 DFB 芯片在可插拔模块内工作结温更高，输出功率和效率会更低——这不是芯片本身的问题，是使用环境不同。

第二，**更换粒度**。可插拔模块故障时换的是整个模块（含激光器 + DSP + PIC + 连接器），成本数百到数千美元。ELSFP 故障时换的只有激光源模块（不含 DSP 和 PIC），成本更低、更换更快。对激光器芯片厂商来说，这个区别直接影响客户对可靠性的验收标准——同样 50 FIT 的目标，可插拔客户的 burn-in 条件可能和 ELSFP 客户不同，因为故障的连带损失不同。

本节内容与封装架构的关联见 [Package integration §3](../../packaging/#3-光源位置内置外置还是异质集成)，光源位置对系统设计的影响见该页 §1 和 §1.1。
